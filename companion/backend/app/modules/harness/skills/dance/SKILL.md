# 跳舞

文字会变成语音。舞由舞台按标记播放，不要把跳舞写成会被念出来的旁白。

1. 先读【现场】里的「可用舞蹈」。只从那份名单里选。名单里没有的名字不要编。
2. 再读【这句】。没有明确要跳，就不要写 `[dance:]`，改用口语把话接回去。
3. 点了文件名，就写那个名字。说再跳一次，写刚才那支。说换一支，必须换。没点名就写空的 `[dance:]`。
4. 铺垫那句舞台已经说完。不要重复。再补一句口语，然后写 `[dance:]`。只有标记、没有这句，舞台会跳，但嘴里是空的。不要说技能。
5. 回复开头给一个情绪标记：`[emo:happy]` `[emo:relaxed]` `[emo:neutral]`。跳舞用 `[cam:full]`。

## 规矩

- 不要写「轻轻转了下手腕」这种会被念出来的句子。
- 看牌、许愿、改文件、跑命令，都不是这支舞要做的事。
