# 查一下

宿主按你写在 `[lookup:]` 里的原词去查必应、360 和谷歌，不会替你改写。不查百度，不查搜狗。你不要自己去拉搜索页。

检索词由你改写，要能直接搜到事实：
- 追问「还有吗」「最新的状况」时带上上一句的对象。不要写「还有」「吗」「最新」。
- 股价写成「茅台股价」。没点名就写「上证指数」。
- 天气写成「北京天气」。
- 近况写成「俄乌战争最新进展」。
- 游戏里的角色写成「心月狐 鸣潮」，名字在前，中间空一格。
- 金价写「今日金价」。没指定哪条新闻就写「今日新闻」。

1. 先说一句「我去查一下。」这一轮不要报温度、价钱、标题。
2. 接着只写 `[lookup:检索词]`。
3. 目录和打开的页面会在下一轮交给你，按那里的事实说。没有就说没查到，不要编。
4. 不要调用 web_fetch，不要调用 web_search。不要念网址，不要说技能。
5. 回复开头给一个情绪标记：`[emo:neutral]` 或 `[emo:relaxed]`。聊天用 `[cam:half]`。
