# 小可爱 · 双视图概念稿

使用内置 ImageGen。图一为用户提供的服饰与发型参考，图二、图三为清漪实机全身与面部参考。

画一张清漪的原创国风游戏角色换装设定稿，横幅，两位是同一位成年角色穿着同一套衣服。图1中坐着的人物只作服装与发型气质参考；图2的游戏角色是身材比例和脸的基准；图3是清漪面部特写，保留这张脸的金琥珀眼、红眼尾、眉形、脸宽和下颌。人物站立。保留东方三维动漫角色的画风和原角色比例。
左边略大，占一半多，清楚展示正面的全身直到鞋尖；右边相同角色转身，后侧四分之三角，露出一边侧脸，让后发结构、肩背和裙片都能读懂。两者大小接近。干净的灰青色中灰棚拍背景，柔和而方向明确的暖白光，白衣在背景上有清晰边缘。无文字、无排版线、无道具、无界面。
发型是淡珍珠银粉的中分长发，发根有灰藕色，发梢染薄樱。两片鬓发自眉骨外翻再沿锁骨落下，轮廓是开阔而松的 S 弯；后发在肩胛以下散开，长度到后腰，发尾有自然的粗细差。有两侧造型不完全对称的浅青琉璃花瓣簪，细银枝串小珍珠，额心一滴很小的水晶。发顶低平、灵动，无动物耳朵，无大头冠。
衣服使用珍珠白小立领露肩上衣、圆润含蓄的交领细节、收腰，中央偏下有一枚掌心大小的原创香槟金镂空花萼形腰饰，托一小块蓝白月光石，向下垂一片细长的花瓣玉坠，设计精工但克制。腰胯两侧轻薄花瓣裙片错叠，前后都保持大腿中段短裙长，内层用不透的柔白丝绸，外层用淡烟紫欧根纱，肩臂处独立窄幅轻纱从银环垂至手边。让腿部轮廓清晰，后腰只有两片到大腿后侧的短纱。珍珠绸、透明薄纱、抛光金属的反光要各自分明，裙片边缘的卷曲与接缝清晰。质感精致但适合实际3D建模，保持设计的呼吸感。金属装饰集中在腰间，服装的大面留白。
