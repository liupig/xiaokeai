# 清漪 · 兰汀短裳

服装以本地鸣潮／白泽模型为底，保留原作的披袖与鞋履。初稿对照[宁荣荣的短装轮廓](https://www.animecharactersdatabase.com/jp/characters.php?id=127900)。定稿观察了模之屋[申鹤「冷花幽露」](https://www.aplaybox.com/details/model/GzBOxBz5Nrky)从前襟延至胯侧的深浅交界、侧后衣片与盘发的关系，以及[「荷亭玉立」言和](https://www.aplaybox.com/details/model/YsoBOcTzipAW)的偏分短发、编发环和独立衣袖。清漪的纸样、玉兰绣花与配件为此次单独制作。

领口为墨青立领、盘扣与两幅合围的花窗前襟。腰下为闭合短衬裙、斜裁前幅、象牙色侧幅和后幅，后腰打结的两片织带随胯部落下。裙片绑定原模型的腰、上下半身与双腿骨骼。腰饰为双绳、金托玉环和不等长的玉坠。烟柳发型的长鬓发梢重新收至锁骨，避免扎入胸衣。

原始绣花存于同目录的 `lanxu-embroidery.png`，由内置 ImageGen 生成。下列提示词用于生成透明刺绣纹样。布料、折线与滚边由 `build_lanxu.py` 随裙片的 UV 曲线绘制。
