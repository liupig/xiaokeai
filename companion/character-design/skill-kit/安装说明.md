# 安装角色制作技能

完整解压 ZIP。Windows 双击 `Install.cmd`，或在解压目录执行 `python install.py`。macOS、Linux 执行 `python3 install.py`。安装器使用 Python 3.8 及以上的标准库，离线复制技能；同版本可重复安装。制作阶段才需要 Blender。安装前如已自行修改过同名技能，安装器会显示冲突目录。

**按用户安装**时，Codex 与 Cursor 共用 `~/.agents/skills/xiaokeai-character-studio/`，Claude Code 使用 `~/.claude/skills/xiaokeai-character-studio/`。设置了 `CLAUDE_CONFIG_DIR` 的 Claude Code 使用该配置目录下的 `skills/`。只安装某一端可运行 `python install.py --target claude`，其余选项为 `codex` 与 `cursor`。

**随项目安装**可运行 `python install.py --project "<现有项目目录>"`。新开会话时用该项目作工作目录。没有 Python 时，手动将整个 `xiaokeai-character-studio` 文件夹分别复制到上述两个个人技能目录，或项目下的 `.agents/skills/` 和 `.claude/skills/`。检查 `SKILL.md` 位于技能目录第一层。

## 调用

- Codex 输入 `$xiaokeai-character-studio`。
- Claude Code 输入 `/xiaokeai-character-studio`。
- Cursor 在 Agent 聊天框输入 `/` 并选择 `xiaokeai-character-studio`，或在请求中直接点名。

例如：“用这个技能，按正面和侧背参考，用我有授权的底模做一个国风短装角色。保留原脸，先做好发型和衣片，再测全身材质、挥手和裙摆物理，交付能在我的舞台导入的 ZIP。”

安装后开一个新会话查看技能。仍未出现时核对实际工作目录、用户配置目录以及软件版本。使用远程工作区时，将技能安装在运行代理的那台主机。升级时若提示同名目录内容不同，先把列出的旧技能目录完整移到技能搜索路径以外作为备份，再运行安装器。其他端若也装过旧版，按同一提示处理。

想先看制作流程，可读[技能入口](xiaokeai-character-studio/SKILL.md)。要让另一个 AI 接手制作，可让它先读[实操手册](xiaokeai-character-studio/references/agent-workflow.md)，从当前舞台加载的角色做一次同镜头对照。

支持的本地技能目录可参阅 [Codex 文档](https://developers.openai.com/codex/skills/)、[Claude Code 文档](https://code.claude.com/docs/en/skills) 和 [Cursor 文档](https://cursor.com/docs/skills)。
