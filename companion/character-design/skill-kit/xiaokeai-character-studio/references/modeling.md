# 造型与局部返工

## 从参考到结构

保留一组已认可的正面、四分之三侧面和背面截图。不同参考各管一件事，例如用底模确定头身和骨架，用设计稿确定露肩领口和短裙，用照片判断粉色长发的垂感。参考只有正面和斜背时，将纯侧面、遮挡处和内部结构记录为推定。复刻程度用相同视角的轮廓和材质对照说明。

1. 对齐地面与头顶，量肩宽、腰宽、髋宽相对于头宽的比例，以及髋、膝、踝相对身高的位置。透视很强的自拍适合看装束，弱透视的站姿更适合量比例。
2. 若要加长腿，分别决定股骨段和胫骨段的改量。同步处理身体、骨骼静止位、膝 IK、鞋和脚踝配件，检查落地、弯膝和相机取景。改肩、腰、胸廓时，把手指、颈部接缝及已有表情键放到保护区域。
3. 核心形体可用工作副本上的灰模确认。正面看中线两侧的轮廓，斜侧看胸廓向腋下的转折，纯侧看胸前衣片离体量。排查局部瘪陷、贴叠三角形、跨 UV 缝的法线不连续和异常权重，再决定是否平滑或补拓扑。角色造型引入的不对称要与基础网格误差分开判断。

## 把用户指的缺陷修到对应层

- **脸和眼。** 从认可过的原脸微调下颌或颧部时，用局部形态键或带衰减的位移。试闭眼、张嘴、笑和侧脸。改眼型时同步核对眼睑边缘、眼白和睫毛；重绘虹膜时沿现有 UV 标出瞳孔、虹膜边和角膜亮点。去痣、去手臂文字先定位所属贴图或独立面片，并补齐周边色阶。
- **手与指甲。** 分开看手掌厚度、掌指根、指节渐细、虎口和甲面嵌入深度。测试自然垂手、握拳和挥手的手背视图。指甲的微凸曲面承担高光，甲色及清漆单独调，避免整只手出现相同亮度。
- **发型。** 用导向曲线定分缝、刘海弧和大束重力方向，再沿大束分成中层和较窄的发片。让邻束有少量长度、弯折与末梢分叉差异；细丝集中在轮廓、鬓角和大束交界。顺发向的 UV、透明发梢和有方向的高光配合，比遍布全头的几何细丝更容易控制。转头检查透明排序、细丝闪点和背面轮廓。
- **发际和头饰。** 先隐藏头发，从仰视检查颅后是否缺面、旧耳根是否有洞。确有空缺时顺原曲率补头皮或发底，接边、法线和头骨权重连续；再用发束藏好发际过渡。替换旧钗时定位它的材质或连通区域，检查斜后视角的新饰品支点、垂坠方向和与鬓发的距离。可换发型按组切换，同时检查原发是否仍参与绘制或物理。
- **衣片、纹样、饰品。** 若请求只针对胸前图案，先做匹配 UV 的图案样张，在原衣片上替换。若要改成抹胸，则从贴合后的躯干推导两侧包覆面、领缘转折、侧翼与后背闭合，分别拟合外层和内边。腰间饰品以合身的衣面为锚点，从侧面复核金边与花心的高度。裙片与手臂飘带要观察静止间距和动作扫过的空间。

## 用同一套镜头反复检查

在 Blender 安装所在终端运行下列命令。尖括号对应这次任务的真实路径。脚本使用当前帧及可见、可渲染的网格；场景有地板、道具或多个角色时用 `--collection` 指定角色集合。默认角色面向 Blender 的负 Y，其他朝向用 `--front` 指定，例如 `--front=x`。

```text
blender -b "<角色.blend>" --python-exit-code 1 -P "<技能目录>/scripts/review_blend.py" -- --out "<对照图目录>" --collection "<角色集合>"
```

比较两版时沿用相同集合、姿势、朝向与分辨率。两版身高有调整时，加相同的 `--height`（正交镜头覆盖的高度，Blender 世界单位）并固定 `--center X Y Z`。头发透明区、丝绸光泽和手绘妆面要在最终应用另外检查。

## 起手时只有参考图

从空的 Blender 工程起步，先统一比例尺、地面与正面轴。在正交正面和侧面搭一个中性 A/T 姿的人台，确定头身、胸廓、骨盆和四肢体块。单张图看不到的颅后与背部先定可转动的体积。在这一版就用两盏不同方向的光看剪影。

沿眼眶、嘴角、肩肘、髋膝和指节布置可变形的环线。分离眼球、睫毛、口腔和指甲；展开头、体和衣片的 UV，再把雕刻细节烘到实时网格。给基础骨架绑一侧肩臂和一只手，先试抬臂、握拳、眨眼和张口。能变形后再细化对称部位、发型与衣柜，可少一次全身返工。已有合适底模时可从相应步骤续做。

新项目先查 Blender 版本、导入插件和目标舞台实际支持的格式。PMX 需要可用的 MMD 导入导出链；GLB 或 VRM 则应按目标加载器支持的骨架、表情和材质扩展试导一个小样。只在涉及相应制作步骤时安装缺少的工具，并记录成功导出、回导的版本组合。
