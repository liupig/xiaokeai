# 全身材质与动态验收

## 从样件扩展到全身

在最终模型里按“有三角面、当前款式可见、运行时实际绑定”盘点材质。记下绘制部位、底色来源、UV、着色器、数据贴图与开关降级路径。模型中存在贴图、Blender 中接好节点、舞台实际采样是三件分别验证的事。

- **金镶、珠母和晶石。** 用同一朵胸花测三类材质。金边有窄而有方向的环境反光；珠母呈更宽的柔光；小晶片应看得到后面的颜色和边缘亮度。给舞台提供可反射的环境。小可爱里双面薄晶片用屏幕折射时随角度变黑，改用双面薄片透明、视角相关的透明度与环境反射；Blender 的厚晶体仍可使用真实透射。
- **丝绸、绣纹和薄纱。** 按衣料走向布 UV，用褶线的尺度决定凹凸强度，给织物留宽而柔的反光。检查前片、侧翼、里层和飘带的反面。把色彩图标为 sRGB，把粗糙度、金属度、遮罩和高度当线性数据。记录每个通道的实际含义；本项目的 R 高度、G 粗糙度、B 金属或织物补偿，不能直接按通用 ORM 连接。
- **长发。** 大束读出体积，细束承担局部高光。检查近景刘海、侧逆光鬓发和远景轮廓；遇到亮点爬动，分别隔离发丝片的透明阈值、深度写入、过强自发光和过细的凹凸。高光跟随发向，保留根部与内层的颜色深度。
- **皮肤、甲面、鞋。** 把脸、躯干、上下肢以及后颈分别映射到真实 UV。不同材质的接缝用同一身体坐标场衰减，遮开同图集上的内衬、发底。皮肤局部区分暖色边缘、粗糙度和镜面权重；手绘风格可叠加受控的柔光与介质高光，并说明实时透光的近似方法。手指甲和脚趾甲保留底色，独立控制清漆高光。鞋面缎带、金属鞋跟、鞋底和鞋面晶石分别验收。

**有效的 A/B。** 冻结相机、姿势、环境、曝光和灯位，只切换材质。再转动角色或把主光移到侧面，重复比较。比较“上一版 → 全身版”时，上一版已经有增强材质的部位要在两边同时开启。记录哪些槽使用物理材质、哪些保留手绘效果，以及增强开关关闭后能否正常显示原模型。

## 绑定与物理

先用无物理模式观察原骨架的活动范围、脸部形态键和权重。新增贴身衣物从邻近、同侧且解剖上对应的表面转权重；限制跨到另一条腿、另一只手或同位置的内外层。新发型和新衣装都要检查实际顶点权重，只有骨名和刚体数量还不足以说明已经随动。

头发链从头骨延伸，裙片从骨盆附近分区，飘带从真正的袖扣或臂饰安装点开始。链根随骨架运动，链末逐级放松；约束按模型尺寸调，覆盖必要碰撞组。先测单链再测整套，调回稳时间、穿模与抖动。对于 Bullet/MMD，关节参考系尽量在写入模型的静止姿势和一致的模型坐标下建立；若用户挥手时开启物理，保存当前姿势，建立约束后恢复并同步刚体。

使用目标应用自带的待机、点头、摇头、挥手和口型。至少对最暴露缺陷的动作测试关闭→开启→停止→回稳，并检查切换服装、复载模型后表现。可以记录链根与链尾的角位移、回稳后的漂移、镜头与模型根骨的姿态。若屏幕闪烁或倒立，固定相机后分别隔离根骨动画、物理初始化、相机近裁剪和透明深度排序。
