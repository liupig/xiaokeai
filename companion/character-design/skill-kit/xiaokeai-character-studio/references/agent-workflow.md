# AI 实操手册：接手一个角色，做到能在舞台上用

## 第一小时先拿到什么

时间随工程大小调整。第一轮最有价值的产出，是一张能复现用户所说问题的图，以及一份能重新生成它的工作副本。

1. **把用户的话翻成编辑范围。** “心月狐这种感觉”“不要狐系”“只改图案”分别指向品质、人物设定和编辑范围。分清哪些来自形体参考，哪些来自服饰设计，哪些是用户已经认可的实机结果。写成一句可执行的任务，例如“沿用当前角色的脸和骨架；将交领另存为抹胸款；从侧面验收领缘、前片和胸花”。遇到较早与较晚的反馈冲突，沿用最新决定，同时保留用户点名要留的旧款。
2. **从人眼看到的版本向回查。** 打开用户给的舞台页，记下选中的角色、衣装、发型和触发问题的姿势。查模型请求或角色资源记录，找到实际加载的文件和同目录材质；再定位对应 Blender 源文件、导出入口与底模授权说明。遇到两个同名 PMX，用相对路径和文件摘要核对。若是空工程，就从有权使用的参考和中性人台开始，先让目标舞台读进一个简单的带骨模型。
3. **保存能重复的拍法。** 固定姿势、相机朝向、焦距和灯位，截一张用户反馈角度，再补一张最能区分原因的图。修改身形、发型或衣片时，用灰模看几何；修改肤色、透明度或光泽时，用实际舞台渲染。新旧两版共用镜头参数，改身高时尤其要锁定画幅。
4. **选对工具和改动入口。** 比较外观方向时画设计图，有明确参考时直接从轮廓、分件和材质落到 3D。雕刻和布线可用 Blender；同一操作要反复跑在多组发束、裁片、UV 或材质上时，写可重跑的 Blender Python 或模型处理脚本。先读工程已有的生成入口：由脚本生成的网格要把改法落到生成步骤，否则下次导出会丢。若以手改的 Blender 文件为准，则从该副本回导一次检查。小可爱的定稿 PMX 与可编辑工程共用制作数据，在别的项目先确认哪一份掌握最终几何。

## 如何把两张参考图变成第一版

把正面和斜背图并排。在正面标出发顶、肩峰、腰部花心、裙边、膝与鞋底，在斜背标出后发最厚的位置、背部衣缘、侧裙最低点。以头顶到鞋底为同一画幅高度。斜背图同时包含旋转与透视，用它判断前后遮挡和衣片走向；纯侧面的厚度先作推定，等模型转到侧面再检查。

例如小可爱的玉兰抹胸，在缩小的全身图上也能读出三件事：露肩的弧形上缘、两片花瓣向胸下花心交叠、短裙在两侧逐层落下。先在 Blender 里用身体、素色衣片、花心定位块和几束大卷发搭出这些轮廓，截同角度的图。对不上时，写清偏差在哪，如“花心偏离腰部中线”或“后发在侧视挡住整条背部衣缘”，再移动相应几何。等这几条线能对上，再投入花纹、细丝、金边和珠光。用户若只改一处，就只对照受影响的标记和原本容易出问题的视角。

## 一次完整迭代是怎样做的

以“正面裙片离身体太远，侧边特别明显”为例。以下是另一位 AI 可以直接执行的顺序。

1. 在当前动作的中性帧取纯侧和四分之三视图。在副本里分别显示身体、衣片、饰品。看身体轮廓是否合理，衣面是否整体前移，或仅胸花离开衣面。若问题只在挥手时出现，先走下文的权重和物理排查。
2. 身体通过后，按高度在胸线、下胸围和腰线取截面；在这些高度记录人体前表面、衣片内面、饰品底座的位置。若截面本身变形，先在中性灰模上修身体，再重复取样。衣料厚度与裁片叠层决定应留的间隙，具体数值按本模型单位设。
3. 在工作副本生成候选衣片。小可爱的具体做法是用修好的身体截面求衣面，再按旧衣面与新衣面的深度差移动花饰顶点，保留金边、花瓣与花心原有的相对浮雕高度。法线随变形更新，新增衣片及饰品从对应身体位置转权重。小可爱工程可顺着 `magnolia_fit.py` 的 `DressForm` 和 `build_strapless.py` 的 `seat_flower` 查看；换底模应重新取截面与锚点。
4. 在相同镜头叠看侧面轮廓。正面检查交叠弧线与花饰中心；侧面检查领口、腰和饰品底座；后侧检查闭合与手臂间隙。任一处还有异常，回到对应层再改。静止通过后，运行抬臂或挥手，观察领缘和花饰是否一起跟随。
5. 将候选导入真实舞台，再看一次最初那张侧视图。把通过的副本升为这一款的基线。若用户已要求完整交付，就接着做材质、绑定和打包；若这轮只要求看设计，则交付已经验证的角度和仍待确定的设计选择。

## 用现象决定下一步

- **“想要好看一点，但不要动脸。”** 把参考和当前角色缩到相同头高，看分缝、顶区高度、脸旁负形、后发长度和外轮廓。方向未定时，用同一脸、同一妆、同一姿态比较少量发型草案。方向已定时，在原发主曲面上分出宽窄不同的子束，根部边界连续，中段沿主波形下垂，末端逐渐收尖并错开长度，最后加少量细丝。脚本生成时固定随机种子，让两次对照只反映本轮修改。先看剪影，再看鬓角近景，最后在转头中看透明发片是否闪烁。
- **“原脸更好看，只微改眼型。”** 找最近认可的脸和它的表情。若要从旧模型恢复，先比对顶点索引和三角面；拓扑匹配才直接迁移。对上、下眼睑及相关睫毛、眼白遮罩施加局部衰减形变。对于位移形态键，新偏移按“变形后的表情位置减去变形后的静止位置”计算，防止静态眼型好看、闭眼却裂缝。正面闭眼与斜侧微笑都通过，才接受本轮结果。
- **“舞台上头饰发黑、头发有白点。”** 保存故障镜头，用同一模型先切原生／增强材质，再分别切晶片朝向、透明方式、凹凸或细发片的深度写入，一次只动一个变量。小可爱试过单面透射，近景黑块减少，但某些薄花瓣只剩边框，拉远仍有黑点。最终对舞台薄片采用视角相关透明度和环境反射，再在近景、全身、侧光复测。头发另调细束高光和透明边缘。遇到新问题先复现，再决定是否沿用此方案。
- **“一挥手，飘带就穿进右臂。”** 固定重现的动作帧，依次看静止、动作且关物理、同动作开物理、中途打开、动作结束。静止已穿插就调裁片和安装点；关物理仍错位就查父骨、同侧权重及根部过渡；仅开物理才错就查刚体、碰撞和关节建立姿势。对比骨与网格末端的实际位移。若整个人倒立，同时固定相机、记录模型根骨与相机的姿态，找出先发生跳变的一方。
- **“已经铺到全身了吗？”** 列出当前款式实际有面并参与绘制的材质，逐槽标记增强、保留原生或待补。衣料、金属、晶片、头发、皮肤和甲面分别验收。小可爱胸花样件通过时，手脚的皮肤和指甲仍用原材质。末版补上四张身体／后颈分区图和两处甲面；对比时让两边的衣饰都保留上一版 PBR，只切此次新增的槽。向用户回答时列出真实覆盖部位，保留手绘的眼部和表情层也说清楚。

## 怎样从一次成功变成可交付结果

**先试难点，再批量。** 让一个样件走完“设计 → 几何和 UV → 材质 → 导出 → 舞台载入”。例如胸花要在同一镜头里读出金边、珠面和晶片；验证通过后，再把相同的处理分别应用于头饰、臂环和鞋饰，并按各自尺寸复测。只有 Blender 好看时，先排查舞台着色器、贴图色彩空间和环境光。

**用故障反测工具。** 缺图检查可以在测试包里临时拿掉一张身体分区图，确认审计工具报出具体路径；再换回正式包验收。动作检查则让角色实际挥手，观察手臂是否离开初始姿势、发尾和裙角是否回稳。文件数量、骨骼数量和 HTTP 成功响应都只能回答其中一部分。

**留下下一位 AI 真能接着用的信息。** 交接时写一段能重放的记录即可，例如“从舞台当前选中的抹胸款派生；修改衣面拟合和花饰支点；固定侧视、在同一挥手帧比较；候选 ZIP 已用正式导入器在干净位置回导；现有角色所指资源已读回核对”。把工程相对路径、款式参数、预览入口与对比图附上。设计图、Blender 输出、应用实拍分开标注。遇到缺模型或无法启动舞台时，仍可完成已具备条件的环节，并明确剩下哪一项缺少实际验证。
