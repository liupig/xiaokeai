# 从参考图到可上台的角色

先认清这次要交什么。完整制作以“用户在目标应用导入交付包、旋转角色并播放动作，看到定稿效果”为终点。局部返工则从对应步骤进入，拿当前认可版本作对照。若用户要先看设计，先给可比较的视觉方案；若已确定参考并要求交付，就接着制作和验证。

## 接手后的第一轮

完整制作、接续陌生工程，或用户反馈“越改越差”时，先读 [AI 实操手册](references/agent-workflow.md)。里面有从参考图到实机的一轮工作示范，以及发型、衣物、材质和物理各自的排查顺序。

开工时用现成的任务记录或几行工作笔记写清四件事：用户认可的版本、这轮允许动的部位、能暴露差异的镜头或动作、最终要交的文件。打开实际资产，制作第一个可比较的样件。每轮亲自打开输出图检查；通过的候选作为下一轮起点，退步就退回最近认可的版本，换有证据支持的做法。已获授权的制作和测试连续做完。只有审美方向确实需要用户选定、缺关键输入或超出原范围时才停下来问。

## 制作顺序

1. **定位基线。** 找到当前舞台实际加载的模型、对应 Blender 工程、底模说明和现有动作。记录骨架、单位、朝向、材质、表情、可切换款式。把可回退的定稿、开发副本、参考图区分开。先确认来源允许预期的改造、用途和交付方式；做可分发的新角色时使用自有或授权匹配的底模。
2. **把审美变成可检查的决定。** 分清“借比例和骨架”“参考发型或服饰”“沿用本人的原脸”。在正面和侧面标出肩峰、腰线、膝位、发际线、领口和裙摆，记录看不见的背面如何推定。用同焦距、姿势和画幅比较。把“只改眼型”“保留旧款”当作本轮编辑边界。
3. **先定形，再贴身。** 在工作副本以中性材质隔离躯干，检查腋下、胸廓、侧腰和左右连续性；再按修好的表面拟合衣片、包边和饰品。用正侧、斜后和仰视找悬空、露底、黑块和穿插。发型、手、五官、服装分别见 [造型与局部返工](references/modeling.md)。
4. **先做一个可信的材质样件，再覆盖全身。** 选择同时包含金属、珠面和晶片的饰品，在真实舞台同灯位下切换新旧材质。通过后按实际绘制的材质槽逐项扩展至头饰、发束、衣裙、手饰、身体、手足和鞋。把有意保留的手绘线、眉睫和表情层单列。见 [材质、绑定与动作验收](references/lookdev-motion.md)。
5. **让模型动起来。** 先用现有骨架和内置动作测表情、手指、肩肘与衣物跟随，再比较物理开关。观察启动、挥手中途开关、停止和回稳。按用户当前应用的实现处理布料和头发，验证随动确实来自绑定。
6. **以导入后画面交付。** 导出一个最终运行模型及其实际依赖，另存可编辑源文件。用正式导入入口把候选包导到干净位置，在真实舞台分别看近景、全身、侧背、动作，核对原有对话、眨眼或表情入口。把用户能打开的预览、最终包、实拍对比和已知边界放在交付回答里。见 [打包与舞台验收](references/delivery.md)。

## 可直接使用的工具

- 需要判断造型时，用 [Blender 四视图脚本](scripts/review_blend.py) 给同一工作副本出正、斜侧、侧、背四张正交灰模图。参考图和实机光泽需要另行对照。
- 准备交付 PMX 时，用 [ZIP 材质审计](scripts/audit_pmx_zip.py) 核对模型实际引用的贴图和可见材质分组。它直接读取 ZIP，能识别本项目的 PBR 辅助清单。
- 在小可爱原工程续作，或想知道这些步骤为什么这样排，读 [项目历程与代码入口](references/xiaokeai-case.md)。在其他工程使用时，先找到该工程对应的底模、加载器和导入器。
