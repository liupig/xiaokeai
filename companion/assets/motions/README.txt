放动作（让她动起来）
====================

支持：.vmd（MMD 动作）
文件名里带「待机 / 打招呼 / 互动 / 舞蹈」或 idle / wave 等，程序会自动分类。

  motions/
    待机-呼吸.vmd
    打招呼-挥手.vmd
    极乐净土.vmd

舞蹈可以再在资产中心绑一首 BGM（文件放到 ../audio 或 ../music）。
PMX 角色跳 VMD 最完整；VRM / GLB 是映射过去的，效果看模型。

不要提交进 git。

Put motion .vmd files here. Name them so idle / greet / dance can be detected. Do not commit them.
