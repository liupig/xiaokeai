xiaoke.ai 资产目录
==================

仓库不带 3D 模型、VMD、音乐（版权和体积）。克隆后这些文件夹是空的，只留说明。
舞台默认是空的，自己导入才会有角色。

怎么放进去
----------
1. 打开应用 → 资产中心，拖 zip / rar / pmx / vrm / glb / vmd（会自动分类）
2. 或设置里填模之屋 token，在线搜索下载
3. 或按各子目录 README.txt，把文件拷到对应文件夹，再重启（或资产中心刷新）

目录
----
  models/    角色模型  .pmx / .vrm / .glb
  motions/   动作      .vmd
  cameras/   镜头      .vmd（运镜；程序也会生成一批内置镜头）
  audio/     某支舞自带的配乐
  music/     舞蹈兜底曲库（没绑 BGM 时用）
  tarot/     塔罗牌面（已随仓库提供，不用自己放）

版权：模型、动作、音乐归原作者。模之屋多数禁止商用和二次配布，不要把别人的包再传上网。

These folders are placeholders. Import your own characters — the repo does not ship 3D models.
