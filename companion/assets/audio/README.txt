放「某一支舞」自带的配乐
========================

支持：.mp3 / .wav / .ogg / .m4a / .flac 等
通常是动作包里跟 VMD 捆在一起的那首歌。资产中心导入 zip 时会自动拆到这里。

  audio/
    极乐净土.mp3          ← 文件名最好和动作对得上

和 ../music 的区别：这里是「绑给某支舞」的；music 是没绑时的兜底曲库。
不要提交进 git。

Per-dance BGM goes here. The shared playlist is ../music. Do not commit audio files.
