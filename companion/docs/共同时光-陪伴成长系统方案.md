# 共同时光：多路陪伴成长系统

状态：多线完整产品闭环已交付，含异常恢复与实机验收
独立模块：`backend/app/modules/journey`、`frontend/src/features/journey`

## 1. 产品目标

共同时光要同时提供四种快乐：

- **升级的快乐**：AI 陪伴等级持续成长。
- **关系被回应的快乐**：角色好感、关系阶段和实际对话表现发生变化。
- **探索的快乐**：逐渐发现角色新的内心片段。
- **付出有回报的快乐**：送礼获得即时演出、明显奖励和永久收藏。

共同故事负责把这些收获串成长期经历，但不再限制其他成长线。

## 2. 一次互动，多线收益

所有成长共用一个后端事件总线，不同线路有自己的用途。

### AI 陪伴等级

- 普通聊天、保存回忆、完成待续话题、共同活动、舒适触碰和送礼都会提供经验。
- 等级永久保存，经验要求逐级提高。
- 送礼结果会明确显示经验收益和升级结果。
- 每级自动生成永久奖励记录，并按等级发放金币；账本确认后才标记到账。
- Lv.2 解锁角色回礼，Lv.3 解锁偏好加倍，Lv.4 解锁套装结算，Lv.5 解锁共同纪念日。

### 角色好感与关系阶段

- 普通互动提供稳定、有限的日常好感。
- 送礼提供显著好感；首次送出同类礼物有额外加成，重复赠送递减。
- 原卡路线使用：初识、熟悉、信任、默契、羁绊、知心。
- 自由心动路线使用：初识、心动、靠近、暧昧、相恋、深爱。
- 路线由用户明确选择。原卡路线不改变角色卡关系；自由心动路线允许相应情感表达，但仍尊重人格与边界。

### 内心发现

- 互动积累内心成长，逐步解锁内心档案。
- 未解锁内容只显示成长条件，不提前剧透。
- 已解锁内容会作为轻微表现倾向进入对话，不覆盖原角色人设。

### 自主人格

- 「最近偏爱」由角色根据原本人设和真实相处形成，用户不能代选。
- 角色保存自己的第一人称自述、偏好理由、当前心境和长期价值观。
- 首次内心整理后，每积累 120 XP 才允许再次整理，避免每天随机改变人格。
- 自主人格作为角色自己的长期连续性进入对话，但角色卡和 Lorebook 始终优先。
- 界面只提供「听她怎么说」，不提供偏好编辑按钮；偏好写入 API 返回 403。
- 真实角色已完成首次模型内心整理并持久保存，重载后可以继续使用。

### 共同故事

- 保留四章：这一刻、我记得、我们的习惯、长久的故事。
- 保存共同回忆、待续话题和认识时间。
- 第二章后，欢迎和主动搭话可以自然承接一件待续话题。

### 礼物图鉴

- 每个已完成礼物订单只发一次奖励。
- 图鉴保存礼物名称、种类、份数、最近好感与赠送时间。
- 首送、重复赠送、高价综合礼物使用不同的明确收益。
- 礼物奖励失败不影响金币订单和商品交付，重试订单也不会重复发奖。
- 达到回礼条件后生成一份带专属文案的永久角色回礼。
- 礼物可设置两项角色偏好，匹配后增加好感与经验。
- 六组心意套装提供收集进度、自动结算和金币奖励。
- 认识 7、30、100、365 天会生成纪念奖励。

## 3. 礼物爽点

一次送礼形成五段反馈：

1. 商品交付与角色回应。
2. 好感与 AI 经验数字跳升。
3. 首送、关系进阶、AI 升级和内心解锁提示。
4. 永久进入礼物图鉴。
5. 用户可主动把这一刻保存为共同回忆。

好感规则：

- 同类首送：基础好感 + 首送加成。
- 同类重复：基础收益减半并设置下限。
- 高价礼物：基础收益随价格平滑增长并封顶，不能无限膨胀。
- 固定剧情模式仍保留图鉴，但暂停成长。

## 4. 日常互动的收益

- 每日有效聊天：共同故事 4、AI 经验 8、好感 2、内心成长 4。
- 保存共同回忆：共同故事 8、AI 经验 16、好感 6、内心成长 8。
- 完成待续话题：共同故事 6、AI 经验 12、好感 4、内心成长 8。
- 共同活动：共同故事 5、AI 经验 12、好感 3、内心成长 6。
- 舒适触碰：共同故事 1、AI 经验 4、好感 1、内心成长 2。

聊天和触碰按日去重；活动按内容和日期去重；回忆与订单按来源 ID 去重。重复请求、重新生成、系统回复、商品预览和许愿次数不提供成长。

## 5. 与角色卡的关系

每个角色独立保存成长，提供三种模式：

- **完整共同时光**：全部互动成长、主动回访与自主人格。
- **安静陪伴**：全部互动正常成长，不主动回访。
- **原卡演绎**：全部互动正常成长，不改变原角色表达。

模式只控制表现与主动行为，不再决定亲密值或经验是否增加；只有模块总开关会停止成长。

导入酒馆卡默认采用「仅共同回忆」和原卡路线，不修改 `first_mes`、人设、示例对白、Lorebook 或导出内容。用户可以主动切换到完整模式和自由心动路线。

## 6. 与金币的关系

- 金币继续负责住宅、餐饮、装饰、车辆和礼物等内容消费。
- 金币不能直接兑换好感或经验；只有实际完成送礼或活动后才产生对应成长。
- 免费聊天、免费活动和付费内容都能成长。
- 礼物提供更强的即时反馈和图鉴价值，而不是只有一句感谢。
- 不改变金币价格、许愿金额、钱包余额和订单幂等规则。

## 7. 界面

入口位于「我们的空间 → 我们的故事」，集中展示：

- AI 陪伴等级和下一级经验。
- 当前好感、关系阶段和下一阶段目标。
- 内心档案解锁进度。
- 共同故事章节、认识天数和回忆数量。
- 礼物图鉴。
- 待续话题与可编辑的关系近况。
- 完整、仅回忆、固定剧情模式，以及原卡／自由心动路线。

送礼结果页直接展示首送、好感、经验、升级、关系进阶和内心解锁，不让用户到另一个页面寻找奖励。

## 8. 技术结构

### 独立数据

`shared_time.sqlite3` 保存：

- `journey_state`：模式、路线、共同故事、AI 经验、好感、内心成长、摘要。
- `journey_events`：事件来源、幂等键和共同故事收益。
- `journey_threads`：待续话题、来源、期限、状态和回访冷却。
- `journey_gifts`：订单、礼物、名称、价格和实际好感收益。

不修改金币账本，不把全局成长放在前端 `localStorage`。

### 现有系统接点

- `modules/hooks.py`：聊天完成事件和对话表现注入。
- `modules/life`：订单完成后的礼物奖励、回忆保存与删除来源同步。
- `features/touch`：舒适触碰事件。
- `features/life/stageLife`：免费与付费共同活动事件。
- `routers/characters`：酒馆卡默认模式和角色删除清理。
- `routers/chat`：清空聊天时清理聊天来源的待续话题。

成长模块异常不能阻塞金币订单、商品交付、回忆保存和删除。
