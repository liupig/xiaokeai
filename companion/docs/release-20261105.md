# xiaoke.ai 2026-11-05 发布说明

**简体中文** · [English](./release-20261105.en.md)

## 这次，她把娱乐活动安排得明明白白

距离 2026-10-28 的 A 程序包一周多，小可爱又学会了不少新本领。

以前，她陪你聊天、跳舞、看电影。现在，她能和你围桌诈牌，能接住直播间的弹幕和礼物，能打开你想玩的游戏，还能把 SillyTavern 里的角色卡请上 3D 舞台。陪看也不再是“看一眼、答一句”，而是真的跟着连续画面往下理解。

**一句话总结：她会玩、会看、会主持，也更会扮演你喜欢的角色了。**

## 魅影酒馆：坐下以后，先别急着说真话

新增四人诈牌对局「魅影酒馆」。

- 你和三名 AI 对手围桌开局，各自根据目标和局面选择跟牌或揭穿。
- 三膛左轮、计分、跟牌与挑战流程完整呈现。
- 四套牌面美术，配电影化裁决和胜负演出。
- 角色可以边说话边玩，语音不再把整张牌桌冻住。
- 不同牌桌角色可以分配不同音色。

她可以陪你演戏，但规则不由模型临时编：牌局、结算和裁决仍由代码执行。

## 直播互动：弹幕来了，礼物也来了

新增抖音和 B 站直播互动能力。

- 接收弹幕、关注和礼物，聚合同一话题，重连时去除重复消息。
- 按消息时效和队列容量安排回应，普通弹幕不会被礼物洪峰彻底淹没。
- 生成完成不等于已经说过：只有舞台实际播放完成，才把回应记作完成。
- 新增本地直播彩排实验室，可用虚构观众、真实或替身模型、正式语音和 3D 舞台完整试播。
- 支持重复消息、断源、模型失败、播放失败等故障演练，以及未完成礼物回应的持久记录与补播。

你可以先在本机彩排，不必一上来就让真实观众检验她的临场反应。

> 直播彩排验证的是本地完整链路。真实平台的鉴权、网页协议变化、限流和长时间稳定性仍需使用目标直播间另行实测，不视为商业上线 SLA 保证。

## 连续视频陪看：这次能跟上剧情了

本地 MiniCPM-V 4.7 1B 视觉能力从截图理解升级为连续原生视频理解。

- 持续采集滑动视频窗口，保留真实时间戳。
- 不再把过期观察请求越堆越多，停止或闲置后自动释放。
- 电影、短视频和音乐拥有各自的场景上下文、字幕时间轴与语言感知。
- 游戏理解可结合英雄联盟客户端状态和本地 OCR。
- 能区分“帮我看一眼这个报错”和“这局陪我看着”，不会每次都把视觉进程一直开着。
- 画面和声音仍留在本机；她不会替你点击，也不会代打。

以前是“你暂停一下，我看看”。现在更像“你接着播，我跟着看”。

## 酒馆角色卡：喜欢的角色，可以请上舞台了

接入 SillyTavern 角色卡生态。

- 导入 v1 / v2 / v3 PNG、JSON 角色卡以及 AICC 卡。
- 导出 SillyTavern v2 PNG 卡。
- 保留多个开场白、作者元数据和原卡未知扩展字段。
- 世界书支持关键词、正则、常驻与选择性条目、注入顺序和位置，以及有限递归触发。
- 可单独填写用户档案，不必为了告诉角色“你是谁”而改写她的人设。

角色卡格式与世界书概念来自 SillyTavern 开放生态；xiaoke.ai 做的是兼容导入、分层提示词接入和 3D 舞台呈现，角色卡版权归原作者。

## 自然语言开游戏：说游戏名，不说安装教程

可以直接让她打开 WeGame、Steam 或 Epic 里已经安装的游戏。

- 解析本机游戏库，按当前意图和上下文选择游戏。
- 启动后检查进程，不把“已经发出命令”冒充“游戏已经打开”。
- 库里没有时只打开对应平台，不擅自安装。
- 只是在讨论、否定或假设某个游戏时，不会误启动。

“我想玩那个”可以说；“陪我玩那个”也可以。她会先开游戏，再准备陪看。

## 语音与表演：更多声音，更少抢话

- 新增小米 **MiMo-V2.5-TTS**，提供 9 个预置音色和情绪指导。
- 改进断句和短片播放，长句不再轻易拖成一整段，酒馆说话也不阻塞操作。
- 普通聊天、重说、塔罗、欢迎、续聊、告别、触碰、Code 伴侣和陪看共用统一的 dsh 角色会话。
- 打断、修正和过期响应有了更明确的处理，旧回答不会串到下一轮。
- 本地 Qwen TTS 回退到已验证的官方依赖组合，修复兼容分支虽然能加载、却可能生成错误语音的问题。

## 桌面与更新体验

- 应用、窗口、托盘和安装器支持共用 Logo 与配色主题。
- 更新检查支持 GitHub 和 Gitee 发布信息源。
- 增加视觉进程日志开关，排查陪看问题更方便。
- 更新窗口控制与社区入口，QQ 群和微信二维码随桌面资源提供。
- 补齐视觉运行时和打包整合，减少源码里能跑、打包后却少组件的情况。

## 升级前看一眼

- 本次发布说明对应 **2026-11-05 新版 A 程序包**，变更范围从 2026-10-28 A 包之后开始。
- 使用 agent A/B 分体包时，请按发布页提供的组合下载，并保持 A、B 时间戳一致，不要混配不同批次。
- 聊天服务商密钥、语音密钥和直播所需凭据仍需自行配置，程序包不会替你附带。
- 本地连续视频和离线语音会占用较多显卡与内存资源；配置较低时可以关闭陪看，或选择在线语音。
