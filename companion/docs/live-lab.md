# 直播彩排交付

这是一套本机可操作的彩排环境。虚构弹幕替代平台输入，后面的注意力选择、LiveHost、上下文、生成、语音队列、播放确认与正式直播共用代码。正式平台配置、模块开关和开播会话不受彩排影响。

## 启动

在仓库根目录打开 PowerShell：

```powershell
.\companion\start-live-lab.ps1
```

打开 `http://127.0.0.1:8610/live-lab.html`，点击“开始彩排”。第一次没有前端产物会自动构建；修改源码后运行 `-Rebuild`。端口占用时使用 `-Port 8611`。Ctrl+C 结束服务。

启动器使用已有 `backend/.venv` 和前端依赖，不安装新软件，不运行正式程序的全盘资产扫描、自动扣费账本、离线模型预热或平台连接。

已有正式后端也会提供 `/api/live-lab`；开发前端的 `live-lab.html` 使用同一套页面。开发代理可通过 `COMPANION_BACKEND` 指向彩排后端，语音直连可通过 `VITE_LIVE_LAB_BACKEND` 指定。

## 如何验收

1. **零凭据体验**：选“脚本替身”和“浏览器中文语音”。完整试播会依次输入进场、情绪表达、游戏提问、刷屏、礼物、追问与冷场。回复由固定场景脚本提供，明确不是模型推理。浏览器语音使用正式 SpeechPlayer；浏览器没有可用语音时会如实记录失败。
2. **真实回答质量**：切换“真实模型”，使用应用已有的模型设置。只发送本页虚构和手动输入的弹幕与人设上下文。模型请求失败会显示原因、播放兜底并计数，不能把兜底播完算成真实模型成功。
3. **产品舞台与声音**：可以加载已安装的 3D 角色，并选择产品配置的语音引擎。无角色时音频舞台也初始化正式表演控制器，不依赖安装模型即可测试播报。浏览器默认语音与产品音色需分别试听。
4. **亲自互动**：填写昵称发弹幕或模拟送礼。查看回应下方的候选消息以及“播放完成 / 播放失败 / 被打断 / 仅文字展示”回执。弹幕速度只改变观众入场速度，不加速语音。
5. **故障演练**：可重复投递、断开源 6 秒、使下一次模型调用失败、使下一轮播报失败、暂停输入、打断播报、停止并重新开播。暂停只暂停弹幕源，已经进入的消息仍会处理。
6. **记录与补偿**：结束后查看验收记录，下载 JSON。失败或中途停止而未履约的礼物会列为待补播，可“补播未完成的礼物”。只有补播的成功回执才会结清原场记录，不会通过点一次按钮就假定成功。

## 四个场景

- 完整试播：58 秒、48 条源消息，包含一次礼物重复重投。
- 低流量与冷场：42 秒、2 条消息，检查情绪接话与主动开口。
- 弹幕与礼物洪峰：30 秒、621 条消息，含 600 条刷屏、18 份礼物与普通问题。
- 连续对话：42 秒、4 条追问，检查选题、上下文、人设与指代。

## 复现自动验收

```powershell
.\companion\backend\.venv\Scripts\python.exe -m pytest companion/backend/tests/test_live_host.py companion/backend/tests/test_live_douyin.py companion/backend/tests/test_live_attention.py companion/backend/tests/test_live_lab.py -q -p no:cacheprovider
.\companion\backend\.venv\Scripts\python.exe companion/backend/tools/verify_live_lab.py
```

第二条命令将四场完整回放写到 `companion/artifacts/live-lab-acceptance.json`。报告里的播放确认明确标记为模拟，不作为真实音频证据。页面导出的记录来自实际浏览器反馈，两者分开保留。

彩排历史落在独立的 `backend/data/live-lab.sqlite3`；每次彩排的接收、入队、选题、模型调用、播放确认和补播收据分别保存。报告不含模型密钥。正式直播的事件持久化尚未被这份彩排数据库替代。

- 后端 43 项测试通过，覆盖原直播能力、四场完整回放、模型故障、接入恢复、播放失败、跨进程补播、播报独占和慢模型不阻塞弹幕接收。
- 零凭据脚本模式已在浏览器实际取得有声完成回执。
- 已配置的真实模型＋浏览器语音：4 条连续追问组织为 3 轮回应，3 轮有声完成，模型调用失败 0。
- 已配置的真实模型＋产品 MiMo 语音＋已安装的 3D 角色：48 条虚构消息，4 轮真实模型回应、4 轮有声完成，模型失败 0，播放失败 0，待补播礼物 0。
- 模型失败、语音失败与源断开已通过页面按钮实际注入。失败礼物在重启后台后仍可恢复；原场的待补播状态必须等真实补播回执才能结清。
- 前端生产构建通过。全仓 `tsc --noEmit` 仍有 lipsync、codewatch、performance、tarot 和 stt 的已有类型问题，未报告直播 TS 模块错误；补齐了 Vue 文件的标准模块声明。

## 验收边界

这套交付用于先在可控环境把体验跑通。真实模型的自然度要实际读听，自动断言不能替代主观体验。真实平台的鉴权、网页协议变化、重连与限流仍应在彩排通过之后单独实测。这里没有声称完成 8 小时真实平台运行或多租户商用验收。
