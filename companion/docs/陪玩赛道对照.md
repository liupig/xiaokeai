# 陪玩赛道对照

2026-10-16。用来决定「集百家之长」时哪些拿、哪些以后、哪些不拿。

对照依据：小可爱当前仓库；AIRI 说明书 0.11.3（2026-08）和仓库路线图；Open-LLM-VTuber 介绍页与 v1.2.0 说明；Amica 官方文档（Amica Life / 插件 / 其他功能，文档本身偏旧）；鹅次元、逗逗的公开报道；SillyTavern；以及桌面/3D 陪伴里已经在卖的 Steam、Quest、移动端产品。商业产品只取公开能力，不把营销句当成已上线。

判定只有四档：

| 档 | 意思 |
|---|---|
| 已有 | 小可爱现在就能用，不要重做 |
| 能做 | 挂进现有导演、全双工、`prompt_stack`、模块开关。不新开一个产品 |
| 以后 | 做得到，但是新运行时、独立进程，或另一块界面。单列排期 |
| 不做 | 做了会拆掉「对面这个人」，或碰游戏代操作、付费墙、依赖死结 |

怎么挂进管线，仍以 [陪玩功能施工图](./陪玩功能施工图.md) 那四条为准：感知变成一句观察，状态只加导演一格，主动开口只加一种句子，新模型不进当前 Python 进程。

## 四家各自强在哪

| | 小可爱 | AIRI | Open-LLM-VTuber | Amica |
|---|---|---|---|---|
| 身体 | PMX / VRM / GLB。MMD 有布料、VMD 舞蹈、运镜审查 | Live2D、VRM、Spine、立绘，也有 MMD。眨眼、看向、待机眼动是标配 | Live2D（含 Cubism 5），点击和视线跟鼠标 | VRM。随机动画、情绪、口型 |
| 声音 | 全双工：边听边说，按句排队或打断。本地 SenseVoice + Qwen3-TTS，或在线 | 浏览器/桌面听写和多套 TTS。说明书写说话时会暂停输入，避免回声 | 声称不用耳机也能打断，模型听不见自己 | Silero VAD，说到一半能被麦克风打断。有唤醒词 |
| 她会不会自己找你 | 会。进页、沉默续聊、再搭话、告别，时间可调 | 意识模块在，主动程度看配置 | 空闲超时，或举手按钮让她开口 | Amica Life：空闲自问、随机动画，久了睡觉 |
| 看见 | 摄像头只用于动捕，不是理解画面 | 视觉模型 + 屏幕/窗口捕获（要单独开 Vision Capture） | 摄像头、录屏、截图 | 上传摄像头或图片；文档里有 LLaVA 一类视觉模型 |
| 动手 | 没有工具协议 | MCP、搜索、生图、Minecraft / Factorio 智能体（多半要另起进程） | MCP（时间、搜索）、浏览器控制、工具状态条 | 往插件目录丢脚本做 Function Calling |
| 记忆 | mem0 + 本地向量，扮演和看牌默认不入库 | 短期有；长期和「记忆体」界面仍在做 | Letta 长期记忆 | 压缩对话日志再影响以后的回复 |
| 别人没有的 | 镜头语法、塔罗仪式、情境卡、证物、盯着 Cursor 的 Code 伴侣、分层人设 | 40+ 聊天服务商预设、Discord / Telegram、手机端、节拍同步 | B 站弹幕、内心想法不念出来、多角色同聊 | 唤醒词、睡眠倒计时、自提示文件 |

AIRI 的 40 家服务商是一份预设清单（xsai），不是 40 套推理引擎。Ollama、vLLM 也是「旁边已经跑着的服务」。这和小可爱「只收 OpenAI 兼容地址」是同一类接口，差在设置里有没有把地址写好。

## 市面上还要看的，不是再开四张产品介绍

| 产品 | 值得拿走的一点 | 不拿的原因 |
|---|---|---|
| SillyTavern | 酒馆卡、世界书、群聊剧本 | 它是文字前端。小可爱要的是导入成提示词层，不是再做一个酒馆 |
| 鹅次元 / 逗逗 | 看游戏画面，主动吹一句；桌宠和壁纸 | 能量计费、代打操作不拿。看画面用「看一眼」 |
| 星野 / Talkie、猫箱 | 角色卡好传播、语音通话像打电话 | 角色市场和会员是平台生意。模型版权多数不许二次配布 |
| Replika、Nomi、Kindroid | 日记、关系阶段、会过问你 | 关系做成羁绊口吻即可。视频通话、AR、订阅不拿 |
| Neuro-sama | 会玩游戏、会看弹幕、像一个真人在播 | 她不是能装回家的软件。游戏智能体和弹幕放到「以后」 |
| Steam《AI Desktop Pet》 | 本机 GGUF、唤醒词、屏幕视觉、工坊人设、语音克隆 | GGUF 用外面的 Ollama，不打进当前环境 |
| NekoGPT、AITuber Kit | 看屏幕、直播评论、人脸在不在 | 直播间是另一条产品线 |
| Desktop Maid | 多个角色互相说话 | 舞台上同一时刻只能有一个人占声音和镜头 |
| Grok 伴侣（2026-09 起下架） | 实时 3D 语音曾经证明需求在 | 不做绑在别人账号里的云宠物 |

## 集齐之后，小可爱仍然比它们多的

这些不要为了「全」拆掉：

- 一句话同时驱动表情、动作、舞蹈、运镜，并且组合要审过才上舞台。
- 全双工的句子池：排队、打断、丢掉、沉默后续聊，是一套节奏，不是一个麦克风开关。
- MMD 布料和 VMD。AIRI 能加载更多格式，但没有这套镜头语法。
- 塔罗是台上的仪式，不是弹窗小游戏。
- Code 伴侣看的是本机开工，不是把 IDE 画面再识一遍。
- 记忆、情境、重写、证物、塔罗、Code 伴侣都能单独关掉。

## 若目标是功能最全，建议的拿法

**现在就能吸收（能做）：** 开口即停、服务商预设、分区触摸、视线跟随、主动搭话加理由、看一眼、睡眠、提醒、羁绊口吻、酒馆卡和世界书导入、三个窄工具、内心独白不念、来电皮、多会话、换装即换已有模型、晨间一条梦。

**以后单独开题：** Live2D、第二个人只出声、语音克隆、生图进相册、常驻看屏幕、某个游戏的词典、Minecraft 类智能体、直播弹幕、Discord 通知、手机、壁纸和托盘、节拍跟舞、MCP 协议外壳。

**不拿：** 付费能量、游戏内代操作、浏览器代点、插件目录、进程内大模型、捏脸、双耳 ASMR、潜意识第二数据库、小说状态栏、QQ 绑定。

施工顺序和每项挂在哪一层，见 [陪玩功能施工图](./陪玩功能施工图.md)。那份是排期，这份是边界。
