## 状态

| 标记 | 意思 |
|---|---|
| 待修 | 还在 |
| 已修 | 代码里已经按下面的修法处理 |
| 已缓解 | 主路径挡住了，边角仍可能再出现 |
| 不修 | 设计如此，或只能在使用侧避开 |

做完一条不要删。把状态改成已修或已缓解，补上修复说明和日期。

## 怎么追加一条

1. 编号接着最大号加。已修用 B-0xx，待修用 B-1xx，不修用 B-2xx。
2. 写清现象、怎么稳定碰到、当时的状态。
3. 修完只改这一行的状态、修复和日期，不要把旧描述删掉。
4. 若其实是还没做的功能，改记到 [TODO](./TODO.md)，本页留一行指向那边即可。
