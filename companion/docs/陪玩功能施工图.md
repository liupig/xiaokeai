# 小可爱陪玩功能施工图

给产品判断用：哪些能加、加在哪一层、建议做到哪一步。勾选表示「做」，不是「已经做了」。

目标不是把 Open-LLM-VTuber / Amica / AIRI / 鹅次元的功能表勾满。小可爱已经占住的是「一个人坐在对面，说话就是一场表演」。新功能要能交回这套管线，否则舞台上会同时跑两套大脑。

## 挂进去的四条规矩

1. **新感知只变成一句观察。** 摄像头、屏幕、工具返回，都写成一段文字，塞进现有 `prompt_stack`（和记忆、情境同一层）。模型仍用 `[emo:]` `[intent:]` `[cam:]` 表演。感知不直接拧骨骼。
2. **新状态只加导演的一格。** 现在导演是待机 / 聆听 / 思考 / 说话（`PerformanceDirector`）。睡眠、被摸、被唤醒都是这一格的扩展。VMD、动捕、塔罗期间自动让位，和现在的闲置动作一样。
3. **新的主动开口只加一种句子。** 全双工已经有 welcome / 超时续聊 / proactive / goodbye（`duplex.py` + 前端 Pool）。提醒、久别、晨间梦话走同一种「要不要播」的决策，不要另写一套定时器去抢 TTS。
4. **新模型不进当前 Python 进程。** ASR / TTS / 向量已经把 transformers 钉死（见 `infer_backends.py`）。本地大模型、视觉模型、语音克隆都走「旁边一个 OpenAI 兼容地址」，或单独进程。

模块继续用现有开关：关掉等于没装。

## 先改口：清单里写「没有」、代码里已经有

下面这些不要再排期重做。

| 清单上的说法 | 代码里的事实 | 还缺的只是 |
|---|---|---|
| 语音无打断 | 有。按句 `interrupt` / `queue` / `skip`；她说话时 Silero VAD 等不到句尾，就按音量切约 1 秒送识别才能插话。AEC3 在消自己的回声 | 不是「一开口立刻停」，是「认出一句再停」 |
| 无 AI 主动说话 | 有。沉默后续聊、再主动搭话、告别、进页 welcome。设置里能调秒数 | 触发条件薄：主要是「安静了多久」，没有时段、久别、提醒 |
| 无待机 / 眨眼 / 视线 | 有。自动眨眼、呼吸、闲置动作池、说话看镜头、思考看向一边、聆听歪头。桌宠空闲会自己走 | 视线不跟鼠标、不跟人脸；没有睡眠这一格 |
| 触碰 | 模块 `touch`，默认开。头、脸、胸、腰、手分区。点一下有短姿态；偶尔才走现有表演说一句。同一处摸多了会腻、会麻、会不理。跳舞、动捕、塔罗不响应 | 还没有单独的好感数值系统。亲疏是触碰自己记的 |
| 视觉完全没有 | 摄像头在，但是 MediaPipe 动捕（骨骼），不是「看见你在干什么」。`/api/omni` 能传一张图给 MiniCPM，是测试口，注释写明不进主进程、不进表演 | 看见图之后说一句 |
| 技术底座只有一个厂商 | 聊天是任意 OpenAI 兼容地址（通义、DeepSeek、火山都能填）。缺的是预设列表，不是缺协议 | 设置里要手填 URL。进程内跑不了 GGUF |
| 仅桌面、无小窗 | Electron 里可以离开舞台，变成置顶透明桌宠。浏览器开发页仍是整窗舞台 | 没有手机，没有 Discord |
| 记忆只有极简 | mem0 + 本地向量库，扮演和看牌默认不入库。情境卡、证物、分层人设、塔罗、Code 伴侣都在 | 没有酒馆卡、没有 Lorebook、没有群聊 |

身体这一格也不是只剩 MMD：VRM / GLB 能热切换，MMD 才有 VMD 舞蹈和布料。Live2D 没有，也不建议加（见文末不做）。

## P0 · 接在现有管线上，体感差最大

做完这五件，陪玩感会明显变厚，而且不新开子系统。粗算都在现有前端导演、全双工和设置里。

### 1. 开口即停

- [ ] 她正在说时，VAD 判定「这是人声不是回声」的当下就停 TTS、停口型，不必等那 1 秒切段识别完。
- 挂法：判定放在现有 `stt.ts` 的说话中切片之前；停播仍走 Pool 的 `interrupt`，不要在 VAD 里直接拆导演。
- 风险：AEC 漏一点，她会被自己的声音打断。要沿用现有回声判断，误触发就退回现在的按句打断。
- 不做：不换一套 Silero，浏览器里已经是 Silero。

### 2. 对话接口预设，含「旁边的本地模型」

- [ ] 设置里给常用 OpenAI 兼容端点做预设：DeepSeek、通义、火山、OpenRouter、Ollama（`http://127.0.0.1:11434/v1`）、LM Studio。选中只填 `base_url` / `model`，密钥仍本地存。
- 挂法：还是现在的 `llm.py` 流式解析。Ollama 由用户自己起，不打进体验包，不进当前 venv。
- 这就是「本机能跑大模型」的正确切法。进程内再嵌一套 GGUF 会和 Qwen3-TTS 的 transformers 版本打架，见文末不做。
- 不做：不抄 AIRI 的 30 家适配器，也不上 xsai。一家不兼容的厂商，用它自己的兼容网关即可。

### 3. 摸一下有反应

已经接上，模块 `touch`，默认开。设置里能关。不要再排期重做。

舞台和桌宠都按头、脸、胸、腰、手分区。点中先做一个短姿态；要开口才走现有表演，种类 `touch`，禁止 `[dance:]`。同一处连续摸会腻、会麻、会不理。跳舞、动捕、塔罗不响应。拖拽仍然只挪桌宠。

### 4. 视线跟着人

- [ ] 舞台：鼠标在画面里时，头和视线轻轻偏向指针，离开后回到现在的「看镜头 / 看向一边」。
- [ ] 开了动捕时：用已经在跑的面部关键点，看向人脸而不是鼠标。
- 挂法：只写导演那一层头部姿态。VMD 播放时继续让位。
- 不做：瞳孔收缩、面捕驱动整张脸。动捕已经能驱动脸，再叠一套会抖。

### 5. 把已经有的主动搭话用厚

不新写 Amica 那套自主状态机。给现有 proactive / welcome 加触发理由：

- [ ] 时段：清晨、深夜、刚打开时的 welcome 口吻不同（prompt 槽，和现在的时间层一样）。
- [ ] 久别：距离上次开口超过阈值，welcome 接那件未完的事（记忆里已有「未完话题」）。
- [ ] 桌宠发呆过久：先换一个闲置动作；再久才开口。现在空闲会走，但很少为「你不理我」找理由。

挂法：仍由全双工的沉默计时决定「要不要生成」。只改提示词和触发条件。塔罗进行中、Code 伴侣开工中、正在跳舞时，计时暂停——这三条现在就要写死，否则主动说话会掀桌。

## P1 · 半个月内能做成模块，默认可关

每一项都是新模块，但输入输出仍是「一段文字 + 一种句子」。

### 6. 看一眼（单帧，默认关）

- [ ] 用户说「看看我」或点按钮：抓一帧摄像头（或一张截图），交给**视觉对话模型**，拿回一两句观察，注入本轮 prompt，她用现有表演说出来。
- [ ] 屏幕同理，单独按钮「看看屏幕」。不做后台常驻截屏。
- 挂法：观察文本进 `prompt_stack`，种类不要进长期记忆，除非用户明确说「记住这个」。
- 模型：走视觉版 OpenAI 兼容接口，或现有 Omni 的云端 / 自建 Gateway。不要把 MiniCPM 装进当前后端进程。
- 和动捕的关系：动捕继续占摄像头做骨骼；「看一眼」是另一路、另一时刻的一帧，不要两路同时抢摄像头分辨率。
- 这是游戏陪伴里唯一值得先做的切片：她能评论你屏幕上的事。代打、代买装备不在这里。

### 7. 睡眠

- [ ] 导演加 `asleep`：长时间无输入，或到了用户设的入睡点，灯光压暗，换躺 / 坐的闲置（没有对应 VMD 就只用现在的放松表情），**停掉** proactive。
- [ ] 唤醒：开口、点击身体、或到点。醒来走现有 welcome 的短句，不要播一场舞。
- 不做：Amica 的「潜意识子程序」。把日志压缩进记忆这件事，mem0 已经在做。不要平行再存一份潜意识。

### 8. 定时提醒

- [ ] 本地条目：时刻 + 一句人话（起床、喝水、自定义）。到点走 proactive 那种短句，带表情，说完即止。
- [ ] 桌宠在小窗里也能响；舞台没开时，至少系统通知 + 下次打开补一句。
- 挂法：句子种类 `reminder`，规则和 goodbye 一样——不追问、不跳舞。
- 不做：经期、用药建议写成医疗能力。文案保持「你让我提醒你的那件事」。

### 9. 羁绊只影响表演，不收费

- [ ] 一个本地数值：聊天、回忆起旧事、摸头会缓慢变化。数值只改三处：闲置动作池的偏好、主动开口的频率、prompt 里的亲疏口吻。
- 不做：能量、次数、会员、抽卡、礼物商城。仓库立场是没有付费墙。礼物如果要做，就是「把一件证物或一句记住的事当成礼物」，不单开货币。

### 10. 酒馆卡和 Lorebook，只导入成层

- [ ] 导入角色卡 JSON（酒馆 V2 的名字、描述、性格、开场白、mes_example）写进现有角色卡的人设层。模型文件仍走资产中心，不从角色卡里带。
- [ ] Lorebook：关键词命中时追加一段世界观，拼进 `prompt_stack`，和情境卡并列，有长度上限。
- 不做：群组剧本 UI、状态栏、HTML 旁白排版、世界书递归。那是另一个产品的阅读器。舞台本身就是状态。

### 11. 窄工具，不是 MCP 浏览器

- [ ] 先做三个工具：现在几点、提醒（接到第 8 条）、检索一段网页摘要。模型通过现有对话发出调用，结果作为额外上下文拼回去，表演标签仍由模型写。
- [ ] 聊天旁一行小字「查了一下时间」，不要做工具调用剧场去挡舞台 HUD。
- MCP：等这三个稳了，再包一层 MCP client，只挂同样窄的工具。协议可以后接，浏览器接管、键鼠控制不要接。
- 和 Code 伴侣的分工：Code 伴侣继续只看本机编码开工收工。工具不负责去点 IDE。

### 12. 晨间一条梦

- [ ] 可选。夜里把当天对话压成两三句「她记得的气氛」，第二天 welcome 可以带出来。存成一条记忆，种类标明是梦，用户能在记忆面板删。
- 挂法：复用记忆抽取，不要新向量库。生成失败就当没有梦。

## P2 · 能做，但会分叉产品，先别排进半个月

### 13. 唤醒词

- [ ] 只建议给桌宠、而且麦没有常开的时候。舞台上现在是用户开麦 + 全双工，再加唤醒词是两套「谁在听」。
- 和睡眠可以配合：睡着后只有唤醒词或点击能叫醒，避免环境噪音把 proactive 喊醒。

### 14. 参考音频音色

- [ ] 用户给一段干净人声，云端 CosyVoice（或单独进程）克隆，合成结果仍走现在的振幅口型。
- 不放进 Qwen3-TTS 那个进程。显存和依赖会和本地 TTS、以后的视觉模型抢。
- 不做：双耳 ASMR、空间音频。舞台已经有运镜，声音方位对陪玩体感帮助小，混音却要重做播放器。

### 15. 角色卡分享

- [ ] 导出 / 导入一份 JSON：人设、情绪映射、音色名、情境偏好。不含 PMX、不含密钥。
- 模型市场继续用资产中心和模之屋。多数 MMD 模型禁止二次配布，不能做「海量 UGC 角色站」。

### 16. 来电皮

- [ ] 主动搭话或提醒时，桌宠先响一声、气泡写成来电，接听才播。挂断走 goodbye 的短句。
- 这是第 5、8 条的外壳，不要单独做通话协议。留言就是一条未读句子，下次打开念。

### 17. 换装 = 换一套已经导入的模型或贴图

- [ ] 同一角色卡挂多套 PMX / 贴图，对话或按钮切换。
- 不做通用捏脸。捏脸是 VRoid 的工作流，PMX 的脸是作者做好的形态键。

### 18. 第二个人

- [ ] 若一定要做：舞台上仍然只有一个身体在表演，另一个只出声音和一句字幕；或者两个模型，但同一时刻只有一个能占 TTS、运镜和舞蹈。
- 上限 2，不做 10 人群聊。多角色同屏会把镜头审查、口型、谁被打断全部打穿。单列排期，不塞进 P1。

## 明确不做

这些在赛道清单里出现过。做了会偏离「对面这个人」，或者碰别人的游戏、碰依赖地狱。

| 项 | 原因 |
|---|---|
| 王者 / 和平里查询战局、买装备、发信号、战术协同 | 那是游戏内代操作，不是陪伴。评论屏幕用第 6 条的「看一眼」 |
| Minecraft 代打、Factorio 视觉代搓 | 游戏里的代理人，是另一个仓库的体量和产品 |
| 常驻录屏、后台看摄像头 | 和第 6 条的边界相反。要用户这一下明确让她看 |
| 进程内 Ollama / GGUF / vLLM | 和现有 TTS 的 transformers 版本不能共存。外部兼容地址已经覆盖 |
| 30+ 厂商 SDK | 维护面换不来体感。预设列表足够 |
| 任意文件夹丢脚本的插件系统 | 桌面端有麦、有本地文件。扩展继续用仓库里的模块开关 |
| Live2D | 第三套角色运行时。VRM / PMX / GLB 已经覆盖身体 |
| 能量、会员、次数卡 | 和产品声明相反 |
| Discord / Telegram 完整分身 | 文字频道里没有身体，等于另写一个机器人。通知一条「她找你」可以以后再说 |
| 手机 PWA 对齐桌面 | 动捕、本地语音、透明桌宠都依赖现在的桌面壳。手机要单独立项 |
| 剧情分支编辑器、好感度商城、情景生图 | 生图会再占一块显存；分支编辑器是视觉小说。证物截图已经是「这一刻的画面」 |

## 建议的判断顺序

若只挑半个月：

1. P0 全部（开口即停、接口预设、触摸、视线、主动搭话加厚）。
2. P1 里先做 **看一眼**、**睡眠**、**提醒**。这三件分别补上清单里的视觉、自主行为、生活感，又都守得住四条规矩。
3. 羁绊、酒馆卡、窄工具、晨间梦，看前三件做完还剩多少注意力。羁绊和梦几乎只改 prompt 和记忆；工具和酒馆卡会碰到解析，容易拖。

群聊、克隆音色、第二个人、换装，单独决定，不混进这半个月。
