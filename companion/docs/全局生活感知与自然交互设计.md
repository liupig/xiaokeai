# 全局生活感知与自然交互设计

角色每轮对话获得一份由后台构造的生活状态：当前在普通舞台、住宅或外出地点，当前住宅和摆放物，已经拥有的住宅、餐饮、车辆与装饰，以及钱包的真实可用金币。前端只提交当前画面状态和商品 ID；商品名称、类别、价格、所有权与余额由后台读取，不能由前端或提示文本伪造。

查看、购买和递送食品是一次性事件。查看商品时，角色可以按人设评价外观、用途、价格和当前余额；购买成功后可以对选择作出反应；食品拖到人物身上时，未拥有的主题先走幂等订单扣款与交付，已拥有的主题直接展示，然后产生“递到角色面前”事件。事件只被对应的生活回复消费一次，不会污染后续每轮对话。

角色回复统一通过现有流式对话与当前角色人设生成。界面只显示订单成功、余额不足等交易事实，不提供冒充角色的固定台词。LLM 可以觉得商品贵、喜欢、犹豫或结合家中已有物品讨论搭配，但不能催促消费、因消费改变关系，也不能声称播放了未实现的拿取、进食或乘坐动画。

生活事件回复不计入聊天赚币，避免反复查看商品形成金币循环。普通用户对话的金币规则保持不变。

食品拖拽使用舞台人物的屏幕骨骼包围区判定，支持鼠标和触摸指针。拖出商品卡片后，只有在人物区域释放才会购买；释放到其他区域不会扣款。余额不足、订单未知或角色切换时保持原有错误与恢复流程。
