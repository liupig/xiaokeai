| 会话记录 | 本场对话，以及后端 talk 日志 |
| 资产中心 | 导入、搜索、下载模型 / 动作 / 镜头 / 音乐 |
| 证物相册 | 按角色看剧照和短片 |
| 放到桌面 | 只在 Electron 里。离开舞台，变成透明桌宠 |
| 设置 | 语言、资源包、体验模块、AI 对话、Omni、语音、下载、画质 |

| 眼睛 | 一起看。默认关。再按一次就停，并关掉旁边的视觉进程 |

## 人设怎么叠

每一轮的系统提示是重新叠的，不是把所有规则写进角色卡。

| 层 | 内容 |
|---|---|
| 身份 | 角色卡里的人设。内置底稿是清宵：面对面说话，不自称客服或别的模型 |
| 扮演 | 临时身份（老师、导游等）能戴上，说「退出扮演 / 变回来」就摘掉，不写进长期人设 |
| 时间 | 深夜、早上、上午、中午、下午、晚上 |
| 间隔 | 第一次聊、正在聊、过了几分钟、几小时、更久 |
| 记忆 | 召回到的长期事实 |
| 情境 | 今晚这场戏 |
| 导演手册 | 表演标签怎么写、什么不能念出来 |
| 红线 | 越界请求在进模型前由代码挡，用角色自己的口吻拒绝，不说客服腔 |

聊天尺度在角色卡里选，挡法由红线层执行：

| 尺度 | 接到什么程度 |
|---|---|
| 清爽 | 全年龄。暧昧也不接 |
| 心动 | 接得住暧昧、若即若离，不主动撩 |
| 可撩 | 撩骚擦边可聊可回撩，露骨仍挡 |
| 恋人 | 亲密称呼、撒娇、吃醋都行，露骨仍挡 |
| 自由 | 不设上限，分寸由人设和对话把握。新建角色默认这一档 |

## 角色卡

角色管理里每一张卡可以设：

- 名字
- 绑定模型（PMX / VRM / GLB，热切换）
- 这张卡自己的音色。空着就用设置里的默认音色。跟着当前 TTS 引擎的音色表
- 聊天尺度（上表五档）
- 人设正文
- 套用人设模板。中文对话有 **27** 个，套用时按角色名代入，会覆盖下面的正文。英文对话只用「通用」
- 打招呼语
- 闲时动作偏好（进闲时池轮换，不是一条死循环）
- 情绪映射：开心、生气、伤心、放松，各自再叠加模型自带形态键。自然是默认，不单列映射
- 删除角色（聊天记录一并失效）

## 表演标签

模型在回复里写这些，舞台实时跟上。

| 标签 | 取值 |
|---|---|
| `[emo:]` | `happy` 开心、`angry` 生气、`sad` 伤心、`relaxed` 放松、`neutral` 自然。可写强度，`[emo:happy:0.8]`，缺省 0.85 |
| `[act:]` | `nod` 点头、`shake` 摇头 |
| `[intent:]` | 见下表。打招呼走审过的动作，不播内置挥手 |
| `[dance:]` | `文件名.vmd`。只有 PMX 能跳 |
| `[cam:]` `[stand:]` | 景别、运镜、站位。组合要过镜头审查 |

表情种类（叠在情绪上，看模型有没有对应形态键）：微笑、星星眼、眨眼、脸红、爱心眼、柔和难过、含泪、皱眉嗔怒、放松脸、惊讶。互斥的不会叠在一起，例如含泪和微笑不同时上。

意图（动作从资产库里按这张表挑，不靠文件名碰运气）：

打招呼、点头、摇头、思考、害羞、比心、亲、鞠躬、坐下、说话、伸懒腰、卖萌、看向、拍手、安慰、逗、闲置、跳舞、走。

景别六档：特写、1/4、1/2、3/4、全身、远景。动作有最小和最大景别，对不上就换镜头或换动作。

导演状态：待机、聆听、思考、说话。说话看镜头，思考看向一边，聆听歪头。自动眨眼、呼吸。VMD 播放时这层让位。VRM 的视线目前看的是镜头，不跟鼠标，也不跟人脸。

同一轮回复按句子切成多段音频，段和段只排队，互不打断。

## 全双工

边听边说。上一轮还在说时，下一轮怎么接，五选一：

| 策略 | 行为 |
|---|---|
| 剩余超过 N 秒才打断 | 默认。N 可调 1–8 秒 |
| 马上打断上一轮 | 新的一问立刻停旧的 |
| 等上一轮全部说完 | 只排队 |
| 不够 N 秒才接，否则丢掉 | 来不及的句子不播 |
| 超过 N 秒才切，否则丢掉 | 剩得少就放弃这句 |

沉默之后她会自己找你，秒数都能调，0 是关掉。每次在附近随机，不会卡在一个整秒上：

| 句子 | 什么时候 | 滑条 |
|---|---|---|
| 进页 welcome | 打开就打一声招呼 | — |
| 超时续聊 | 安静一会儿，把刚才的话接上 | 0–40 秒 |
| 再搭话 | 更久没人说话，她主动找话题 | 0–90 秒 |
| 告别 | 你一直不开口 | 0–300 秒 |
| 会话总长到了也告别 | 之后不再自动说话，你开口才继续 | 0–60 分钟 |

插话分流可以关。开着时：正在跳舞，说「跳得真好」不会停，说「换一支」才会停；正在说话，嗯、啊先记下，问句才开新一轮。语音也等出字再判，不会一出声就掐正文。麦克风一响，续聊和欢迎会先停。

## 一起看

## 金币

2026-10-20。本机账本，不登录、不上传、不和别的电脑对齐。1 枚 = 1000 毫币。余额只从加密账本重放出来，界面改不了存档。编译私钥留在打包机的 `.env` 里，不进仓库。

### 挂机

按挖矿来记。时间倍率是 1、显卡倍率是 1 时，基础是每分钟 2 枚。

连续在线的时间倍率：

| 在线多久 | 倍率 |
|---|---|
| 不到 30 分钟 | ×1 |
| 30–60 分钟 | ×1.5 |
| 1–2 小时 | ×2 |
| 2–4 小时 | ×3 |
| 4–8 小时 | ×5 |
| 8–16 小时 | ×8 |
| 16–24 小时 | ×12 |
| 满 24 小时之后 | 每再满 12 小时 +4。24–36 小时仍是 ×12，满 36 小时是 ×16 |

显卡系数看 `nvidia-smi` 的显存，结果在盒子里缓存 300 秒：读不到是 ×1；不到 4GB 是 ×1.2；不到 8GB 是 ×1.5；不到 12GB 是 ×2；不到 16GB 是 ×2.6；再大是 ×3.4。这块机器是 8GB，时间 ×1 时每分钟 4 枚；连续大约 45 分钟（时间 ×1.5）是每分钟 6 枚。预览里已经得到的毫币不会把显卡系数再乘一次。

### 聊天

4000 token 记 1 枚。不够 1 毫币的零头留到下一次。单次最多按 20 万 token 计。中日韩一个字算 1 token，英文大约 4 个字母算 1。流式回复里如果带了 `usage.total_tokens`，用那一个数，不再自己估。空回复不加。加币失败也不打断对话。

### 许愿池

一天 50 次，按本机日历日。说「我要许愿」「许个愿」「再许一次」「许愿池」「玩许愿」，或正好说「许愿」/「wish」，和个人中心的「直接许愿」走同一套。她刚约了许愿池，回一句「可以」「好」「来」也会打开。用完之后当天不再发，到本地零点恢复。失败的那次（比如服务没起来）不扣次数。

每次都是盒子先抽 3 样不重复的东西。东西先扔进池子，停一下，再下金币雨。

| 正经 | 大约系数 | 恶搞 | 大约系数 |
|---|---|---|---|
| 工作、手机 | 1.0–1.2 | 烦恼 | 1.4–2.2 |
| 电脑 | 1.0–1.3 | 磁铁 | 1.3–2.1 |
| 手串、钥匙、信 | 0.9–1.2 | 信用卡 | 1.5–2.4 |
|  |  | 闹钟、一只袜子 | 1.2–2.0 / 1.2–1.9 |
|  |  | 周一例会 | 1.4–2.3 |

恶搞的系数更高，同样的底金会多一些。每样东西的系数当场另掷，所以同一组东西，两次金额不一样。

底金大约二十次里有一次是 30 枚，其余是 2–12 枚。三样系数按十分之一加总，底金乘这个和再除以 30（三样都是 1.0 时结果就是底金），然后四舍五入成整数枚。最少 1 枚，最多 80 枚。字幕、旁白、金币雨的说明和记忆用的是同一个整数。金额只在盒子里定，模型不能改。

有对话密钥时，模型用当前回复语言说一句旁白，必须带上这个整数。说空了、超过 80 个字、或句子里没有这个数字，就丢掉。前端改说本地的结果句。开场那句是本地说的，不等模型。

长期记忆开着、并且当前有角色时，只维护一条以 `[wish]` 开头的事实：累计玩了多少次、这次扔了什么、落下多少枚。再许一次是改这一条，不另插一行。记忆写在后台线程里，慢或者失败都不把已经发出的金币收回来。

画面：许愿池每次随机出现在角色屏幕的左边或右边。三件道具从另一边远处扔进来，各有自己的延迟、弧线、翻滚和由大到小的变化，然后落在水面上。道具是绘图接口生成的立体物件，绿幕抠成透明图，放在 `assets/wish/items/`。结算金币不掉回池子，从池子的另一侧、画面顶部一直落到画面底部，密一些。雨是气氛，固定用一整组金币，不是一枚金币一颗模型。落下时有一段合成的金属碰撞声，没有单独的音频文件。

水面和金币图在 `assets/wish/pool.png`、`assets/wish/coin.png`。要重画，在 `companion` 里运行 `python scripts/generate_wish_art.py`。密钥读 `scripts/.env`，不打印。已经大于 10KB 的文件会跳过。
