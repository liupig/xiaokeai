# 塔罗：和她面对面抽牌

第一款互动玩法。不是独立小游戏窗口，是「她坐在你对面给你抽牌」。

**本仓库走定位①：内嵌娱乐小插件。** 图新鲜、做活跃，不当商业化主线，不靠塔罗赚钱。牌面由代码定，解读由角色用自己的口吻说。视觉进现有 Three.js 舞台，和站台同一套渲染。

人设怎么写见 [`persona-guide.md`](persona-guide.md)。会话分层见 [`persona-stack.md`](persona-stack.md)。本文管：给谁用、合规边界、玩法放哪、怎么亮牌、怎么进进出出。

---

## 1. 产品定位：先想清楚给谁用

市面上能变现的 AI 塔罗，用户大约 70–85% 是女生；主力付费是年轻女性职场群体。男性很少为算塔罗付费，多数点进来玩一次就走。

陪伴产品若男性占比高，硬把塔罗当核心功能，流量跑不通，转化会很差。

### 两种定位（只做一种）

| | 定位① 内嵌现有项目 | 定位② 独立女性向产品 |
|---|---|---|
| 用户 | 现有陪玩用户（男性偏多也无所谓） | 年轻女性，感情 / 职场 / 自我成长 |
| 角色 | **娱乐小玩具**，非核心模块 | 商业化主线 |
| 视觉 | 跟着现有舞台和角色，不另开吉普赛帐篷 | 吉普赛神秘氛围：帐篷、水晶、蜡烛、柔美插画 |
| 功能 | 单牌、三牌阵，口头抽、看完就收 | 问题引导、多牌阵、打磨解读、情绪梳理 |
| 商业 | 不做付费墙；最多轻度次数限制 | 免费几次 + 深度解读付费 / 会员次卡 |
| 预期 | 好玩、活跃；不要指望收入 | 留存和付费靠解读共情，不靠水晶蜡烛 |
| 风险 | 低。当趣味插件 | 国内审核下架风险高；网页 H5 相对稳，小程序要谨慎 |

**本项目只做定位①。** 定位②是另一条产品，不要在陪伴仓库里做半套吉普赛 H5。

男性向「道人、道观、佛祖观音」盘子小，且和现有角色 identiy 打架，也不做。

氛围感只是外壳。真正让人再抽一次的，是解读是否接得住情绪。页面漂亮但输出空洞套话，用完一次就走——插件版同样成立。

调研：有机会问身边会玩塔罗的女生「你在意什么」，不要只靠脑补。插件版不必等调研才开工，但解读口吻不要闭门造车成算命腔。

## 2. 为什么先做塔罗（插件版）

- 天生就是面对面 + 看牌 + 听她讲，和「同一间屋子里说话」对得上。
- 规则短：洗牌、抽牌、摆阵。状态机很小。
- 模型擅长接情绪和解读，不擅长当发牌机。
- 牌要能看见，正好叠在 3D 角色身边，不必切走舞台。
- 当作趣味玩具：有人玩、图新鲜，就够了。

真心话、抽签属于同一类管线，以后可复用。21 点、成语接龙、答题赛会把她变成主持人或题库，先不做。

## 3. 合规与版权

国内不要讲算命、预测命运。包装成 **心理视角、情绪梳理、娱乐文创**。页面或首次抽牌标注「仅供娱乐，不构成建议」。

| 禁止 | 改成 |
|---|---|
| 算命 / 占卜 / 预测命运 / 「你会」「下个月必」 | 看看牌、抽一张；讲心情和眼下这件事 |
| UI、overlay、她的台词里预言未来 | 接情绪，给一个可以想一想的角度 |
| 抄韦特彩图、描现成牌面 | AI 重绘；可留传统符号（愚者、塔、星），构图和画风原创 |
| 水晶帐篷当另一套产品皮 | 牌面可以神秘一点，但人还站在现有舞台上 |

入口话术用「抽一张」「给我看看」「帮我看看这张牌」。人设和 overlay 里不要写「占一卦」「算一算」。

## 4. 分层：别写进人设

人设里不要写「你会塔罗、牌义如下」。模型会编牌、中途改牌、把牌义念成百科。

对照现有 prompt 层：

| 该放哪 | 放什么 |
|---|---|
| 代码（发牌机） | 洗牌、抽几张、正逆位、牌阵位置。这一轮亮了哪几张，模型不许改 |
| 会话 overlay（像 L3 扮演层） | 「你们正在看牌。牌已经摊开：…。仅供一起看看，不要预言。」 |
| 角色卡 | 不动。她还是本人，只是这会儿在给你看牌 |
| 前端插件 | 升圈、洗牌加速、抽牌飞出、散场落下。走 `StagePlugin`，不写进 `Stage` 本体 |
| 记忆 | 看牌过程不当长期事实入库；她随口记住的心情可以留 |

进场、退场走扮演那套：

- 进：「抽一张」「给我看看」「帮我看看这张牌」
- 出：「收起来」「不看了」
- 模糊的「算了」不要当成退出。允许 1–2 轮惯性，或退出后再补一句系统侧「牌收起来了」。

不要把这次看牌写进长期人设。看牌过程默认不写入账号长期记忆（与扮演段 `kind="rp"` 同类隔离）。

## 5. 视觉：两层，都在舞台里

围一圈、和抽中的牌贴脸，是两件事。必须进现有 Three.js 场景，不要用 HTML/CSS 去围着她转——镜头会绕人转、她会左右走动，DOM 对不上透视。

牌是场景里的薄片（`PlaneGeometry` + 正反贴图），挂在角色根节点上，跟站台、灯光同一套渲染。

插件版 **不要切到吉普赛帐篷 / 道观算命摊**。人还在今晚这场戏里，牌从她身边升起。

### 环绕层（发牌仪式）

牌从台面升起，在胸口到肩的高度围一圈，慢慢转。这是气氛，不是 78 张真牌库存。

### 前景层（抽中的牌）

抽到的 1～3 张从圈里飞出来，停在她和镜头之间（胸口略前），正面朝镜头。要看清再往镜头再推一点。

不要同时再盖一张巨大的屏幕 HUD，焦点会打架。需要点选、看牌名时，用字幕或点那张 3D 牌。

```
台面 ──升起──▶ 牌背围圈（转） ──抽出──▶ 1～3 张飞到身前（翻面）
                                      │
                                      └ 她用一两句口语讲这张牌
```

### 不要升起 78 张真牌面

全套韦特 78 张。围一圈全亮牌面会花、挡人，显存也贵（78 张 1K 贴图很容易上百 MB）。

| | 做什么 |
|---|---|
| 圈上 | 12～22 张**牌背**（复用一张背面贴图） |
| 逻辑里 | 78 张牌库照常洗、抽 |
| 飞出来的 | 只有抽中的那几张换成 AI 牌面 |

大阿卡那 22 张如果想亮面围一圈，当仪式用可以；不要默认 78 张正反都围着转。

### 镜头要让路

平时半身 / 特写很近（FOV 30，人几乎铺满画面），牌圈会裁切、贴着镜头。

发牌时强制拉到 **3/4 或全身**，圈升完再把抽中的牌送近。抽完可以回到半身，牌留在她身前。角色走动时，牌圈跟着根节点走，不要钉在世界原点。

牌要朝向镜头（billboard 或轻微倾角），避免看成一条薄边。雾效在 6～14，牌留在镜头约 3 米内。

## 6. 互动怎么接

TTS 约束仍然有效：短句、禁止 markdown、禁止旁白。牌义细节给模型看，不要让她照着念。

留存靠解读共情，不靠牌面特效。解析是灵魂：先让人看见牌上的画，再让这张画自己贴上来。不是宣判，不是鸡汤，也不是人生建议。沉的牌也漂亮，那是这副牌的味道。每张三到五句短口语，用句号换气。禁止空洞套话，禁止诊断腔，禁止预言腔。

看牌师只是临时 overlay：她还是本人，这会儿坐对面给人看牌。人设卡不动。收起来后 overlay 卸掉。

每一场都走同一套仪式，只换牌位数和牌位名。**不要自动连讲**：她只讲当前翻开的那一张；没点翻的不许提前讲。

```
选玩法 → 可选问一句 → 她洗牌 → 你切牌 → 从牌背点选（或说「你来抽」）
  → 背面落入牌位 → 点一张才翻开 → 她只讲这张 → 全翻后她收线
  → 点牌追问 / Clarifier 一次 → 收起来
```

玩家可做：开口或输入问的那件事；点一次切牌（决定正逆和抽序的种子）；从扇形牌背点出这一阵需要的张数；点背面才翻开；讲完一张后点另一张或问「这张什么意思」；综合后仍可追问；Clarifier 再翻一张补在被点的那张旁边（每场限一次）；「再抽 / 换牌」换一副重跑仪式；「收起来」退场。

发牌由代码完成，正逆位由切牌后的 RNG 定，模型不许改名改正逆。

例如代码已经抽出「隐者 / 正位」，她可以说：「蓑衣老者站在雪山顶，灯芯是一颗星。这张不急着给你答案。灯在他自己手里。」然后等你接。

### 普通

| 类型 | 入口 | 牌位 | 她何时开口 |
|---|---|---|---|
| 日抽 1 张 | 「抽一张」「日抽」 | 今日 | 切牌 + 点翻这一张后讲完，直接进追问，不自动续第二张 |
| 是否 1 张 | 「是不是」「要不要」 | 倾向 | 同上。正偏是、逆偏否，她讲的是倾向不是天命 |
| 时间线三张 | 「抽三张」「过去现在未来」 | 过去 / 现在 / 未来 | 每点翻一张讲一张；未翻完不要自动讲下一张；全翻后收线 |
| 行动三张 | 「现状阻碍建议」「建议阵」 | 现状 / 阻碍 / 建议 | 同一套三张引擎 |
| 身心三张 | 「身心」 | 心 / 身 / 气 | 同一套三张引擎 |

### 进阶

| 类型 | 入口 | 牌位 | 布局 |
|---|---|---|---|
| 二选一 | 「二选一」「两条路」 | A 现况/阻碍/走向，B 同，最后总建议 | 左右两路 + 中间总建议 |
| 关系五张 | 「关系阵」「感情阵」 | 我、对方、连接、卡住、潜力 | 横排 |
| 事业五张 | 「事业阵」「职场」 | 现状、优势、挑战、机会、行动 | 同一套五张引擎，只换牌位文案 |
| 凯尔特十字 | 「凯尔特」「十字阵」 | 现况、挑战、根、近过去、目标、近未来、自我、外界、希望恐惧、出路 | 十字 + 右侧一列，缩尺以免糊成墙 |

爱情五张和职场五张不是两套游戏。不做月亮/节日阵、年度 12 张、付费问卷。以后要加阵，只加牌位表。

同一张牌放在「阻碍」和「建议」意思完全不一样，位置由代码写死。

综合那一轮收尾带一句「就当图个乐子，别拿去拍板」。禁止「一定会发生」、报告体标题和 emoji。没问具体事就按眼下这口气讲，不要盘问「你想问什么」。

## 7. 牌面素材（AI 做图）

全套 80 张的逐张设计见 [`tarot-cards.md`](tarot-cards.md)（大小阿卡那画面、出图 prompt 模板、命名、验收清单）。

发牌那一瞬间不要现画。事先做好、进资源库、发牌前预加载。

- 统一竖版，约 **2:3**（例如 768×1152），带牌框和牌名，平面就是一张完整的牌。
- 同一套光、同一套边框。背面单独一张（可烫金 / 暗纹）。
- 可留传统符号，**构图和上色必须原创**，不要描韦特彩图。
- 画风跟现有角色能站在一起（清宵是国风舞台，不要突然变成另一套吉普赛卡牌宇宙）。
- 颜色空间 **sRGB**，和舞台贴图一样，否则发灰或过曝。
- 第一版可以只做 22 张大阿卡那；小牌用花色 + 数字底板也够用。
- 资源建议：`companion/assets/tarot/`（正面按 id，背面一张 `back.png`）。

不要让模型「描述一张牌」来代替贴图。

## 8. 和现有代码怎么接

游戏做成可开关模块，和记忆 / 情境 / 证物同类。关掉等于没装。

| 层 | 建议位置 |
|---|---|
| 发牌机 + overlay 文案 | `backend/app/modules/tarot/` |
| 模块开关 | `modules.flags` 增加 `tarot` |
| prompt 注入 | `prompt_stack` 在 L3 扮演旁加一场「看牌中」片段；牌面由发牌机填槽，不让模型抽 |
| 3D 升圈 / 飞牌 | `frontend/src/engine` 的 `StagePlugin`（动捕同款接入） |
| 入口 UI | 快捷面板或口头触发；不要另开一页 |
| 免责 | 首次抽牌或设置页一句「仅供娱乐」 |

舞台已有 `StagePlugin`（`onAvatarReady` / 每帧 `applyPose`）。塔罗插件只负责物体和动画，不驱动骨骼。

overlay 示例（代码填槽，不是模型编的）：

```
你们正在看牌，牌已经摊在她面前。
这就是现在的现实，不要说「我们来玩塔罗」「我来给你算命」。
仅供一起看看心情，禁止预言命运，禁止「你会 / 下个月必」。
禁止念牌义百科，禁止空洞套话，禁止一次把所有牌讲完。
一两句口语，先接对方的情绪，再碰这张牌。

牌阵：日抽
1. 隐者 · 正位
```

## 9. 落地顺序（内嵌最简清单）

定位① 的 MVP，到此为止：

1. **单张日抽**：口头触发 → 镜头拉开 → 牌背升圈 → 一张翻开飞到身前 → overlay 注入 → 她讲一小段。
2. **两套三张阵**：过去 / 现在 / 未来，以及现状 / 阻碍 / 建议。背面横排、依次翻开，按张讲，最后收线。可点某张追问。
3. **免责一句** + 模块开关。问卜可选：话里夹着那件事就当问题；没问就按眼下讲。

不做：付费深度解读、会员次卡、问题引导问卷、多牌阵商城、牌库收藏 / 合成 / 对战、吉普赛独立皮肤、切到小程序。那些是定位② 或养成游戏。

## 10. 反例

| 不要 | 要 |
|---|---|
| 当核心功能、指望靠塔罗变现 | 可开关的娱乐插件 |
| 切到吉普赛帐篷或道观算命摊 | 人还在现有舞台，牌从身边升起 |
| 人设里写塔罗牌义表 | 代码抽牌，overlay 只告诉她「已经摊开哪几张」 |
| 算命 / 预言命运话术 | 心理视角、接情绪、仅供娱乐 |
| 抄韦特彩图 | AI 原创，可留传统符号 |
| 特效很炫、解读是套话 | 一两句共情，比水晶蜡烛重要 |
| HTML 牌围着角色转 | Three.js 薄片，跟角色根节点走 |
| 78 张正面围一圈 | 圈上 12～22 张牌背，只翻抽中的 |
| 发牌时现用 AI 出图 | 预先生图、预加载 |
| 抽中的牌再盖一层巨大 HUD | 飞到她和镜头之间，需要时点这张 3D 牌 |
| 特写镜头下直接升圈 | 先拉到 3/4 或全身 |
| 「算了」立刻散场 | 明确「收起来 / 不看了」才退出 |
| 把占卜当长期记忆 | 过程隔离；心情可以留 |
| 21 点 / 成语接龙当第一款 | 塔罗、抽签、真心话这一类 |

## 附录：定位② 不在本仓库做

若以后单独做女性向塔罗 H5，才需要对齐：吉普赛 UI、感情内耗 / 职场抉择引导、三牌阵打磨、解读共情、免费几次 + 深度付费。国内优先网页，谨慎小程序。那是另一份文档、另一个产品。
