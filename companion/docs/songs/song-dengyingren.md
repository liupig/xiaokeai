# 《灯影人》— 原创国风歌词（Suno 可用）

> 创作时间：2026-09-02
> 说明：仿平生不晚「戏腔流行化 + 叙事戏核」风格的原创歌词，可自由使用、修改、投喂 Suno。
> 戏核：皮影戏艺人——演尽别人的故事，自己藏在幕后。

## 歌词正文

【主歌一】

一盏灯 挑起夜色沉沉
白布幕 隔开两种人生
牛皮刻就 王侯佳人的名
竹签轻挑 千年兴亡无声

巷口锣鼓 敲碎几更
看客来去 换了几盏灯
影人鞠躬 替古人把泪忍
我躲在幕后 不敢出声

【副歌】

灯前演尽 别人的爱恨
灯下无人 问我手冷不冷
影过处 山河皆入梦
影散后 只余一盏灯

半生藏在 方寸白幕中
把人间悲欢 唱给了风
若你也曾 为影人动容
便是与我 隔着岁月相逢

【主歌二】

油灯芯 烧短几分晨昏
旧影箱 锁住多少王孙
刻刀游走 眉眼皆有灵魂
一开一合 都是别人的缘分

【戏腔段】

哎呀——
幕上刀马 幕下尘
影里春秋 影外人
灯花爆处 惊破一帘梦
醒时犹自 把签儿横

【尾声】

灯熄了 影人倚着箱沉眠
我把故事 收进下一盏灯前

## Suno 用法

### 1. 模式选择

使用 **Custom Mode**（自定义模式），分别填写 Lyrics 和 Style of Music 两栏。

### 2. Style 提示词（粘贴到 Style of Music）

```
Chinese guofeng pop, ethereal female vocals, Peking opera xiqiang falsetto accents, dizi, guzheng, erhu, modern pop percussion, mid-tempo, melancholic, cinematic, storytelling
```

- 戏腔不明显时，把 `Peking opera xiqiang falsetto accents` 换成更强的：
  `prominent Chinese traditional opera vocal style, dramatic falsetto`
- 想要更现代的编曲可加：`electronic elements, modern C-pop production`

### 4. 实操提示

- 中文歌词直接粘贴，不用转拼音。
- `[Bridge: Chinese opera style, falsetto]` 里的英文描述是引导戏腔的关键，别删。
- 段落标签用英文（`[Verse]` `[Chorus]` `[Bridge]` `[Outro]` `[End]`），Suno 识别最稳。
- 生成后戏腔段不满意，可用 v4 的 **Replace Section** 只重抽 Bridge。
- 一次生成两版，挑戏腔转换更自然的一版再 Extend / Upscale。

## 风格对应说明

| 手法 | 对应平生不晚的特点 |
|------|--------------------|
| 皮影艺人作戏核 | 《难却》戏子、《宝钏叹》王宝钏的叙事传统 |
| 灯 / 幕 / 影 / 竹签意象群 | 高密度古典意象，画面先行 |
| 「影过处 山河皆入梦 / 影散后 只余一盏灯」 | 短句对仗，咬字点留给戏腔甩腔 |
| 戏腔段独立成桥 | 流行打底、戏腔点睛的演唱结构 |
| 「不敢出声」「问我手冷不冷」 | 克制的悲凉，不直白的遗憾 |

- 更夫：守着别人的夜，报尽别人的时辰
