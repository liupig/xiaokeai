# 塔罗牌面设计：80 张

配套 [`tarot.md`](tarot.md)。80 张 = 78 张正面（22 大阿卡那 + 56 小阿卡那）+ 1 张牌背 + 1 张空白底板。

走国风路线，和现有舞台、角色站得到一起。每张保留传统塔罗符号（愚者的崖、塔的雷、星的水瓶），**构图和上色原创，不描韦特彩图**。

---

## 1. 全局规范

| 项 | 规范 |
|---|---|
| 尺寸 | 竖版 2:3，出图 768×1152（或 1024×1536 再缩） |
| 色彩 | sRGB。整体偏暗底亮主体，方便叠在夜色舞台上 |
| 画风 | 国风插画：工笔线条 + 水墨晕染 + 局部泛金，墨蓝夜色底（与牌背同调）；不要厚涂欧美奇幻，不要日系赛璐璐 |
| 文字 | **出图不带任何文字**。牌名、编号后期统一排版叠上去（AI 画字不可靠，也保证 78 张字体一致） |
| 牌框 | 出图不带框。框做一张独立 PNG（描金云雷纹边），代码或批处理统一叠加 |
| 正逆位 | 正面构图必须上下分明（有天有地），旋转 180° 一眼能看出是逆位 |
| 牌背 | 必须 **180° 点对称**，否则从牌背就能看出正逆位 |
| 人物 | 不画现有角色（清宵等）的脸。牌是道具，不是角色立绘 |

### 四花色的国风替换

| 传统 | 本套 | 元素 | 主色调 |
|---|---|---|---|
| 权杖 Wands | **灯火**（每张一种火的形态：灯笼 / 烛 / 炬 / 烟花 / 孔明灯 / 烽火） | 火 | 墨蓝底 + 暖赤金火光 |
| 圣杯 Cups | 青瓷莲纹盏 | 水 | 墨蓝底 + 青瓷莹光 |
| 宝剑 Swords | 青锋古剑 | 风 | 墨蓝底 + 霜银剑光 |
| 星币 Pentacles | 星纹玉币（玉璧刻五角星） | 土 | 墨蓝底 + 翠金玉光 |

四套小牌与大阿卡那、牌背同用墨蓝夜色底，花色主色只做画面亮点，保证整副牌摆在一起是一套。

大阿卡那不归花色：墨蓝紫底 + 泛金主体，比小牌华贵一档。

### 构图原则（国风之美）

| 要 | 不要 |
|---|---|
| 单一视觉中心 | 多个主体抢戏 |
| 背景夜色远山或留空，透气 | 元素塞满、烟尘战场 |
| 色彩克制，暗底亮主体 | 红黄金棕全堆 |
| 疏朗、和谐 | 热闹、乱、脏 |

灯火牌尤其禁止：满屏大火、云中巨手、人群混战。

## 7. 牌背与底板（2 张）

| 文件 | 用途 | 设计 |
|---|---|---|
| back | 牌背（环绕圈全部用它） | 墨蓝底描金：中央一具星象罗盘，外圈云雷纹回环。**必须 180° 点对称**，转半圈看不出差别 |

第一版只出图 22 张大阿卡那 + 牌背 + 底板（24 张）就能上线：56 张小牌先用 blank + 花色图标 + 数字排版顶着，之后分四批补图，一批一个花色。

### 批量出图（火山 Seedream）

脚本：`companion/scripts/generate_tarot_seedream.py`，牌面清单：`companion/scripts/tarot_manifest.py`。

```powershell
# 1. 复制 companion/scripts/.env.example 为 .env，填入 ARK_API_KEY（已在 gitignore）
# 2. 或临时设置：
$env:ARK_API_KEY='你的key'

cd e:\BingCode\bingGames\games
companion\backend\.venv\Scripts\python.exe companion\scripts\generate_tarot_seedream.py --workers 4
```

- 模型默认 `doubao-seedream-5-0-pro-260628`，`watermark: false`
- **默认 4 线程并行**（`--workers 4`），每张约 50s，80 张大约 15–20 分钟
- 已存在且大于 10KB 的文件自动跳过；`--force` 覆盖
- 网络 / 5xx 自动重试最多 6 次
- `--only major` 只跑大阿卡那；`--dry-run` 只看待生成列表
- 日志：`companion/assets/tarot/_logs/run-*.jsonl`

## 8. 逐张验收清单

每张出图后过一遍：

1. 关键符号在不在（愚者的犬、塔的雷、星的双壶……缺了重画，符号是「这是哪张牌」的唯一凭据）
2. 上下是否分明（旋转 180° 能不能一眼认出逆位）
3. 无文字、无水印、无边框（字和框是后期叠的）
