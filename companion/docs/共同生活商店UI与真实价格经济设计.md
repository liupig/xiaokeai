# 共同生活商店 UI 与真实价格经济设计

## 目标

金币不对应真实货币，也不能充值。现实价格只用于建立商品之间可信的价值关系；金币价格表达需要投入的陪伴时间。普通聊天、地点切换和基础共同活动始终免费。

## 经济尺度

- 基础产出为每分钟 2 金币，连续陪伴逐级提升，8 小时达到每日最高连续倍率 5 倍；不再无限增长。
- 心意与一餐是当天可以达成的小目标；住宅和汽车是跨周、跨月的长期目标。
- 住宅等长期资产展示现实参考价与金币目标；车辆只保留当地原价，购买金币数与原价数值一致，不设置“共同生活价”。
- 参考价只用于价值锚定，不构成报价、促销或现实购买建议；汽车以当地厂商建议起售价为基准。
- 永久商品不重复收费；用户已有商品不因调价失去所有权。

## 信息架构

出门页拆为两个互斥视图：

1. 目的地：按散步、自然、约会、文化、烟火和日常筛选，地点免费进入。
2. 共同车库：按当前界面语言自动选择当地市场，再按城市、主流、家庭、EV、高端、豪华等等级筛选。

目的地增加至 14 个，包括公园、海边、山间、湖边、咖啡馆、书店、屋顶影院、海洋馆、美术馆、夜市、茶饮店、餐厅、火锅店和共同厨房。

## 汽车市场规则

- `zh-CN`：中国大陆在售品牌与人民币参考价。
- `ja`：日本市场品牌与日元参考价。
- `en`：美国市场车型与 MSRP。
- `ko`：韩国市场品牌与韩元参考价。
- `ru`：俄罗斯当地常见品牌与卢布参考价。

车辆商品保存 `brand`、`model`、`market`、`tier`、`reference_price` 和与原价数值一致的金币价格。界面只展示当前市场，避免把多个国家的车型堆在同一个列表。
